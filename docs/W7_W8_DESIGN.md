## 2. W7：成熟周期与季节

### 机制

1. **季节**：世界有周期 `seasonTicks`（每个季节的步数）和 4 个季节（春 / 夏 / 秋 / 冬）。当前季节 `s(t) = floor(t / seasonTicks) mod 4`。观测里加环境级字段 `season`（≤ 120 个 ASCII 字符的自然语言提示，如“the days are growing short and the leaves are turning red”）。**提示只说当前季节的现象，不说价值**。季节提示有若干同义写法，随机选取（由模拟器的随机源决定，可复现）。
2. **成熟阶段**：每个语义种类 k 有固定的相位偏移 `o_k ∈ {0,1,2,3}`（由世界种子决定），当前阶段 `stage_k(t) = (s(t) + o_k) mod 4`，四个阶段：0 青涩、1 成熟、2 过熟、3 腐败。
3. **价值随阶段变化（隐藏）**：营养类的因子乘子：青涩 ×0.2、成熟 ×1、过熟 ×−0.4、腐败 ×−1（即从营养变成有害）。有毒类不随阶段变化（始终有毒；青涩时因子乘 1）。乘子表属于隐藏真值，只用于模拟器结算与度量上限。
4. **描述随阶段变化**：观测里的 `desc` = 原描述 + 阶段短语（阶段短语库按方言撰写，如“still green and hard”“at its peak”“going soft and sour”“rotting where it lies”）。`desc` 的 ASCII 长度上限 240 不变。因此个体的信念键是“阶段化的描述”，信念天然随阶段分开。
5. **账本**：与现有语义层一致（`semanticLoss`、在途、死亡损耗）；阶段只改变结算时使用的因子，不改变能量守恒。

### 配置与关闭

`Config.semantic.ripening?: { seasonTicks: number; cues: 'language' | 'off' }`。缺省（未设置）时行为与现在逐位一致；`cues: 'off'` 时环境提示与阶段短语都不出现，但价值仍随阶段变化（用于度量“线索的价值”）。控制组还有 `cues: 'shuffled'`（把阶段短语随机配给其他阶段）。

### 先验的新入口

阶段化描述是新的文本，需要 Laya 先验。按阶段短语库 × 池重新计算（4 个阶段 × 池大小），按文本缓存。不需要新的模型能力。

### 学习侧

个体的信念键沿用描述；季节提示作为额外的上下文：新基因“线索信任”（是否用季节提示预测价值变化——例如：看到季节提示变化时，提前淡化旧信念）。是否需要新基因由预实验决定，**不是预先承诺**。

## 3. W8a：地形与威胁

### 机制

非食物的语义对象 `hazard` / `feature`，每个有描述（自然语言）与隐藏效果：荆棘丛（移动代价）、薄冰（伤害）、洞穴（休息恢复）、“巨大的影子”（捕食者在若干步后到来的预兆）。个体可以选择避开或进入。需要新的行为：绕行 / 避险。动作空间扩展会改变请求格式，因此该部分改动最大，放在 W7、W8b 之后实施，并先做设计评审。

## 4. W8b：社会观察

观测的 `neighbors` 字段：视野内邻居的**可见状态**的语言描述（“脸色发青、浑身发抖”“精力充沛”），由邻居的能量、最近的冲击事件生成（模拟器生成，不共享参数或内部经验）。对照：描述打乱、关闭。观察学习需要个体把“邻居刚吃了 X 并发抖”关联起来，因此邻居**吃的东西**的描述也需要可见（“它刚咬了一口像……的东西”），这是可见行为，不是内部状态。隔离原则保持：不共享策略、信念或梯度。
