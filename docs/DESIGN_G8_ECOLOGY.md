# 设计草案 G8：放进连续生态——先天（遗传）与后天（一生内学习）同时起作用

状态：**草案，待用户审阅后再决定是否开工**。未写任何实现代码（`packages/evo/ecology-probe.ts` 是开发期探针，不是本设计的实现）。本文中的阈值、数字都是草案，冻结前要用开发期世界校准。来源：`docs/RETURN_TO_ORIGIN.md` G8、`docs/ECOLOGY_PROBE.md`。

## 1. 要回答的问题

预注册 17、18 的结论来自“固定 8 个个体、不繁殖、不替换”的世界。初心里的生命是**会繁殖、有寿命、先天遗传、后天各自学习**的。要问：

1. **保留是否真的转化成生存优势？** 反转的环境里，会“分账本”的先天结构（regime）与普通学习（plain）相比，种群更容易存续、更容易从反转中恢复吗？
2. **（探索性）先天结构本身会不会被选择出来？** 允许基因组在繁殖时小幅变异，种群里哪种结构的谱系留下来？

第 1 个是确认性问题；第 2 个只做描述性探索（见 §3）。

## 2. 开发期探针告诉了我们什么（`docs/ECOLOGY_PROBE.md`）

- 现有个体放进繁殖世界可以直接运行；繁殖、谱系继承、寿命更替正常，没有撞上人口上限。
- 默认参数下，约 1/4–1/3 的世界种群无法建立（出生数只有 7–11）。这是世界对繁殖太难，不是个体对比，必须先解决。
- 混合种群里类型占比相互矛盾（初始 8 个体 plain 占优多，16 个体 regime 占优多）：种群很小，一个谱系就能占满全场，漂变主导，不能读成选择。

## 3. 设计

### 3.1 两条线，先做确认性的一条

**G8a（确认性）**：**固定的先天基因组**（复用预注册 17 已冻结的 laya 基因组，不重新训练），孩子继承父母的类型，不变异；后天（信念）一生内从头开始、不遗传。度量的是“结构的生存价值”。
**G8b（探索性，另行决定）**：允许基因组在繁殖时按小的高斯噪声变异并遗传，长时间运行多代，描述进化出的基因（如 regime 的 θ）与结构占比。**这一步是算法层面的新增（进化发生在模拟里，而不是外部 ES），我不会在未经你同意的情况下开始。**

### 3.2 主比较：纯种群并排（首选）而不是混合种群

混合种群（plain 与 regime 同场）会引入互相竞争、一个谱系占满全场的漂变（探针已见），统计上很吵。首选的主比较是：

- **每个基因组各自单独成一个种群**（初始个体都是同一类型），在**同一批世界种子**里并排运行（配对：同一世界、同一食物排布、同一反转日程，只换类型），度量种群的存续与规模；
- **混合种群作为次要比较**，并且**必须带中性对照**（两个“类型”其实是同一个基因组），用来量出漂变本身会把占比拉到多偏。

### 3.3 世界与校准

- 世界：留出方言池，K=6，危害封顶 1，A/B/A/B/A（每阶段 1200，共 6000 tick）和 A/B/B/B/A 两种日程；开启繁殖与寿命；不变异身体特征；无线索（线索作为次要变体）。
- **繁殖本能**：固定规则（合法动作里出现“繁殖”就繁殖），基因组里没有繁殖决策。这是对世界规则的简化，要在设计与论文里明确披露；是否让繁殖阈值也成为基因，列为 G8b 的选项。
- **校准（只用训练划分的世界、独立的世界种子，不用评估世界）**：在少量候选参数（食物供给、繁殖阈值、初始个体数）里，选一个使“**中性对照下种群建立率 ≥ 90%**”的世界；**判据先写，再跑**；若找不到这样的参数，则把“建立失败”作为单独的结局统计（不丢弃这些世界）。校准结果进入文档；评估世界的参数一旦选定就冻结。

### 3.4 基因组与先验

使用预注册 17 的 laya 基因组 {plain, dual, regime}（8 个训练种子各一）为主；无先验（none）基因组作为次要（先天 / 后天 / Laya 先验的分解）。cue 学习器需要线索世界，放进次要变体里。

### 3.5 度量（分析单位 = 训练种子，8 个；每个基因组在 M 个世界里运行，取世界均值）

- **存续率**：种群存活到地平线的世界占比；
- **平均种群规模**（最后两个阶段）；
- **恢复**：每次回到 A 之后一个阶段内的种群规模，相对前一个 A 结束时的比；
- **出生总数**（繁殖产出）；
- 同时报告**中性对照的离散度**（同一指标，两个同基因组“类型”之间的差），作为“差异大到不能归因于漂变”的参照。

### 3.6 假设草案（冻结前会用开发期世界校准阈值；配对符号翻转检验，Holm 校正）

- **H1**（反转世界里 regime 更容易存续）A/B/A/B/A：regime 的存续率 − plain 的存续率 ≥ +0.15；
- **H2**（种群规模）A/B/A/B/A：regime 的平均种群规模 − plain ≥ +15%（相对 plain）；
- **H3**（反转后恢复）：regime 的恢复比 − plain ≥ +0.10；
- **H4**（长停留）A/B/B/B/A：同 H2；
- **H5**（不拖累）部分反转 A/B′/A：regime 相对 plain 非劣效（种群规模，边距 −10%）；
- **H6**（混合种群）regime 的谱系最终占比 ≥ 0.5 + 中性对照离散度的 95 分位（只在混合世界里，且只在建立成功的世界上）。

**预期**：H1–H4 可能不成立。预注册 18 里 regime 的优势体现在“吃对率”，而种群存续还取决于能不能攒够能量去繁殖，不一定放大；**不成立也要如实记录**。

### 3.7 不变量

模拟器拥有世界；类型 / 基因组由测试框架按谱系分配，不是个体的输入；个体看不到谱系、隐藏的环境状态；Laya 固定；后天信念不遗传；预言机只用于度量；先天、后天、Laya 感知三个来源分别标注。

## 5. 风险与限制

1. 校准过程可能找不到“种群稳定建立”的世界；那时 G8 的主结论只能建立在“建立失败也是结局”上；
2. 繁殖本能是固定规则，结论只对这个简化的繁殖机制成立；
3. 先天基因组在 3 段世界里训练（预注册 17），这里评估的是外推到繁殖世界；
4. 种群小，M 与世界数要足够大才能压住漂变；
5. 世界与方言池仍是作者撰写、单一模拟生态；留出池被多次评估；
6. 这一步仍不回答“Laya 是否理解环境”。

## 6. 需要你决定的事项

1. 是否按 §3.2 的方案：**主比较是纯种群并排（配对世界），混合种群只作次要并带中性对照**？我建议是。
2. **G8b（基因组在模拟里变异）是否留到 G8a 出结果后再决定？** 我建议留到之后，因为它是算法层面的新增。
3. 繁殖本能用**固定规则**（不让它成为基因），是否可以？我建议 G8a 用固定规则，避免把“繁殖策略”与“学习结构”混在一起。
4. 校准只在训练划分世界上做、判据先写，是否可以？
5. 论文仍暂停；本步不涉及对外发布。
