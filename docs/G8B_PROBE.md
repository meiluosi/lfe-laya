# G8b 小探针：基因组在繁殖时变异，会出现可检测的选择方向吗？（开发期，非确认性）

日期：2026-10-28。用户授权：做 G8b 的小探针（“按你的建议，先做 G8b 的小探针”）。本探针**不进入任何预注册**，只回答“值得不值得做正式的 G8b”。判据在运行前写下（本节），结果另节追加。

## 1. 问题

G8a（预注册 19）显示：在会繁殖的反转世界里，分账本的结构相对普通学习没有可检出的存续优势。若让基因组在繁殖时小幅变异，自然选择能否在**基因层面**产生可检测的方向（后代基因系统性地朝某个方向移动）？若选择压力弱，基因只会随机游走，正式的 G8b（长时间多代进化）就没有信息量。

## 2. 实现（算法层面的新增，仅在评估框架里，开发期）

`packages/evo/ecology-run.ts` 新增可选 `mutation: { sigma }`：孩子的基因组 = 父母的基因组 + 独立高斯噪声（标准差 sigma；第 8 个基因“延迟信用窗口”量纲大，噪声乘 10）；每个个体用**自己的**控制器与基因组；后天信念不遗传，从头开始；繁殖仍是固定本能；类型/基因组由测试框架按谱系分配，不是个体的输入。模拟器本身不变。测试：sigma = 0 时的逐个体路径与原共享控制器路径逐位一致；噪声确定性；孩子基因 ≠ 父母基因。

## 3. 设计（训练划分世界；开发期基因组 201、202 的 plain 与 regime，laya 先验）

- 世界：S1 校准选定的繁殖世界（供给 20、出生阈值 26、初始 16，训练方言池，A/B/A/B/A）；纯种群；每个（种子，类型，sigma）24 个世界，世界种子 800000 起（训练划分，与校准重叠，不是评估世界）。
- sigma ∈ {0（对照）, 0.15（进化训练用的噪声尺度）, 0.5}。

## 4. 指标与判据（先写）

1. **可行性**：各 sigma 的种群建立率相对 sigma = 0 下降不超过 0.10（否则变异本身把种群毁了，正式 G8b 需要更小的 sigma）。
2. **方向一致性**（核心）：每个世界取“代数 ≥ 2 的个体”（至少 5 个）的平均基因组减去初始基因组，逐基因除以其噪声标准差得到位移向量；各世界位移向量两两余弦的平均值 = 方向一致性（随机游走下期望约为 0）。零分布：每个世界的位移向量随机置换基因坐标，重复 200 次，取 95 分位。
3. **读法（运行前写定）**：
   - **有方向性选择的迹象**：某 sigma 下，该类型两个种子的方向一致性都 ≥ 0.20 且都高于零分布 95 分位 → 值得设计正式 G8b；
   - **没有可检测的方向**：所有 sigma、类型下方向一致性的绝对值 < 0.10 或不高于零分布 → 选择压力弱，不建议做正式 G8b（至少不在当前世界与基因表示下）；
   - 其他情形 → 不确定，不据此做决定。
4. 描述性：各 sigma 下最后两阶段平均个体数、最高代数。

## 5. 预期与限制

预期：G8a 里个体层面的差异很小，选择压力可能也弱，方向一致性可能接近 0。限制：2 个开发期种子、24 个世界、一种世界；基因组是进化好的 ES 解，在其附近的随机变异多数是中性或有害；一个选择信号弱的结果不排除别的世界或别的繁殖机制里有选择。
