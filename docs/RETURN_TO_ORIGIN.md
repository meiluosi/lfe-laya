# 回归初心：一生内的学习、适应、遗忘与恢复

状态：2026-10-25 起草。用户决定：论文不急（暂缓，不再追加预注册来“丰富论文”），主力回到项目最初的验证目标，论文只做低成本的并行维护。

## 1. 初心（来源：README、docs/LEARNING.md）

同一个生命能否 (1) 在一生中根据后果学会新的生存方法；(2) 环境变化后继续适应；(3) 旧环境返回时保留或恢复已有能力（A/B/A）？并通过规则、固定 Laya、记忆适应、无 Laya 小网络等对照，判断学习和 Laya 各自起了什么作用。前端要让人看见这个过程，算法优先，三种体型共存。

## 3. 开发期探针（非确认性；`packages/evo/aba-probe.ts`）

漂移世界（`drift`：每 1200 tick 翻转一半种类的影响，0–1200 为 A，1200–2400 为 B，2400–3600 又是 A），8 个个体，窗口 200 tick，指标 = 每窗口吃到的食物里营养食物的占比。手工基因的结构化个体（遗忘率 0 / 0.05 / 0.2，先验 laya / none）：

1. **K=32（默认世界）**：个体在一生里几乎学不到（占比约等于盲规则 0.5–0.6），翻转与否看不出差别。一生 3600 tick 内每种食物只吃几口，A/B/A 无从谈起。说明默认的难世界不适合这个问题。
2. **K=6（16 个世界）**：能看到学习（laya f=0：A 段占比 0.57 → 0.85）、翻转后的适应（B 段首窗约 0.70 并回升到约 0.85）；**但回到 A 时首窗又掉到 0.57，与第一次进入 A 时的 0.57 一样，没有节省**——即使遗忘率为 0。原因：信念是整个一生的平均，B 段经历把 A 段的知识平均掉了，没有“这是哪个环境”的上下文，也就没有恢复。无先验个体（遗忘 0）回到 A 时 0.62（初次 0.54），略有节省但噪声大。

结论（开发期、线索）：现有个体能适应但不能保留；可测的 A/B/A 需要小 K 的世界，并且需要有记忆的学习器才有机会出现“节省”。

## 4. 路线（并行）

**主线（初心）**
- **S1 度量**：定义并实现 A/B/A 指标：窗口内营养食物占比 / 净摄入；适应时间（翻转后回到翻转前水平所需 tick）；节省 = 返回 A 的首窗成绩 − 第一次进入 A 的首窗成绩（同一批个体）。预先写出判据与阈值。（先在现有个体上预注册检验“是否有节省”，预期无，作为基线。）
- **S2 带上下文记忆的学习器**（算法改动，需先讨论）：候选设计——(a) 变点检测 + 每个“环境”一套信念，返回旧环境时调出；(b) 快慢两套信念（慢的保存长期，快的追踪当前），按近期预测误差选择；(c) 外部记忆（情境→已知信念）。进化决定检测灵敏度 / 混合权重等先天参数，信念本身是后天。路线 D 的边界不变：Laya 固定，先天 / 后天 / Laya 分别标注。
- **S3 对照与分解**：规则、盲规则、固定 Laya、无 Laya、学习开 / 关（病变）、有 / 无上下文记忆；分别度量先天（基因组）、后天（一生内学习）、Laya 先验对适应与节省的贡献。
- **S4 前端**：观察台里加一条“适应与保留”的时间线（翻转标记、窗口成绩、节省），默认简洁，细节按需展开。

**并行（论文，低成本）**：不再新增预注册；只做文字收口、引用核对、AI 披露，冻结在已有 16 批预注册；是否发布等用户指示。
