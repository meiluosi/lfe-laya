## 本轮修订

1. 经历浏览索引与当前世界片段分离，避免查看旧记录改变世界。
2. 死亡状态绑定 L-017，而不是跟随“当前选中”转移到别的生命。
3. 加入 0.1 秒显示，使单步反馈可见。
4. 世界画布填满档案等高列，减少多余空白；窄屏采用纵向档案。
5. ECharts 按需加载；弹窗标识、焦点范围、示例说明与数值表补齐。
