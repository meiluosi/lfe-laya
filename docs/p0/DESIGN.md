## 入口与结构

运行 `npm ci`、`npm run dev` 后访问 http://127.0.0.1:5173。构建检查使用 `npm run build`。需要支持 WebGL 的浏览器和满足 Vite 要求的 Node；本轮在 Node 24.7.0 下运行。`package-lock.json` 固定本轮依赖。

[六视图线框](wireframes.svg) 记录信息层级。视觉候选直接以可点击原型为准，截图为此次实现的导出，避免维护另一套不一致的静态稿。

## 视觉约定

- 以蓝绿水域与苔绿界面构成显微观察室，浅绿强调当前对象和主要操作；灰紫表示冻结分支，虚线提供颜色以外的区别。
- 页面背景 `#091310`，面板 `#11201c`，正文 `#dfebe3`，次要文字 `#83988b`，操作强调 `#c2dba8`。
- 系统字体优先，中文使用 PingFang SC / Microsoft YaHei；时间、ID、版本使用等宽字体。不加载远程字体和素材。
- 生命由代码绘制的双层膜、细胞核、颗粒和细丝组成，无外部图片资产。感知环只显示选中对象。
- 桌面：左侧导航、中央世界、右侧档案、下方四段经历。弹窗容纳成长与对照，保留完整原型标识。
- 窄屏：世界、生命档案与经历纵向排列，成长/对照使用可滚动弹层。与初稿的“底部抽屉”相比，本版先采用纵向档案，减少画布被持续遮挡；用户走查后再决定是否改为抽屉。
- 首版视觉为候选，尤其小号注释、生命辨识度和信息密度需要用户评价，不声称完成无障碍审计。

## 数据与行为边界

所有示例位于 [src/demo.ts](../../src/demo.ts)，包括按固定公式生成的 48 个生命位置、L-017 四段人工经历、两条人工对照曲线。不是推理结果或训练证据。

- 演示时钟以 100ms 定时回调推进，动画位置由演示 tick 和 ID 计算；无生态更新、能量结算、碰撞或 Worker。后台定时器可能被浏览器节流，演示时间不是性能测量。
- 生命周期、等待和错误由“演示状态”选择器触发。L-017 死亡不影响其他个体的存活显示。灭绝时保留预设经历入口。
- 暂停停住动画时钟；单步增加 0.1 演示秒；倍速为 1/2/4。弹窗打开时暂停演示，关闭后恢复原有暂停选择。
- 学习开关仅展示允许/冻结的语义，不更新参数。剧情跳转显式载入预设片段，不能当成冻结状态下仍发生了真实训练。
- 浏览经历使用独立浏览索引，不修改世界片段和当前策略版本。其他个体无经历时显示空状态，不借用 L-017 的记录。
- 投放和障碍仅改变画布，必须先预览后应用；不驱动生命响应。待应用点最多保留 20 个；应用后的点在本次页面会话保留，重置清空。
- 对照固定为“没有改善证据”的示例。曲线可交互，数值表可展开；不启动任何实验。
- 存档入口解释回放与继续训练的差异；没有保存、导出或恢复成功的伪提示。

## 第二轮：减少说明，先比较生命形态

用户反馈：主页面描述性文字偏多；生命形态和运动需要更仔细设计，希望先看到图片或可直接操作的项目。

已修订：取消默认开场弹窗，移除主标题口号，默认折叠性状/记忆与演示片段，将学习说明放入操作说明；保留顶部“示例数据 · 未连接模型”。核心选择、干预、成长与对照入口保留。

新增独立的 [角色动效试验](../../public/creature-studies.html)，开发服务入口为 `/creature-studies.html`。柔团、尾游、节虫三种原创草案可投食、休眠、唤醒、重置与暂停。它们仅用于评审轮廓、运动节奏和即时反馈，不运行 AI、生态或强化学习，也尚未替换工作台的生命渲染。

第二轮曾建议先选尾游；第三轮用户要求至少三种角色，这一三选一建议已撤销。三种基础体型同时保留，继续打磨外形与运动。外部参考与证据边界见 [视觉参考](REFERENCES.md)。


## 第三轮：三种生命共存

用户认可三种造型均可保留，希望至少三种角色，并认为此前外部项目视觉一般。因此不再要求选择单一体型，也不再以这些项目作为美术目标。

动效页新增同一水域中的九个脚本个体，每种体型三个；投放营养提供九个各自绑定的目标点，角色接近后消耗目标并显示总次数。可以全局暂停、恢复和重置水域。单体观察与早期机制参考默认折叠。此处不存在资源争夺、避碰、繁殖、学习或生态结算，不把靠近同一投食区描述为合作或竞争。尚未替换主工作台生命渲染。

下一轮美术重点是轮廓辨识、身体层次与动作表现；至少三种体型为明确方向，精致生态缸、角色性格或连续互动的优先级待用户反馈。不给模型预设“勇敢/聪明”等人格结论。

## 第四轮：算法为核心，展示保持简洁

用户要求继续并明确最终效果取决于算法。三种共存形态保留；后续不以更多脚本追食、固定性格或预设剧情替代行为算法。画面默认展示世界和干预，经历与实验细节按需查看；真实效果通过 [M0 首个算法验证切片](../m0/FIRST_EXPERIMENT.md) 开始验证，再按既定阶段接入。当前共存页仍是动效原型，本轮未改变其算法能力。
