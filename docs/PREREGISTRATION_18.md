# 预注册 18：保留的边界（部分反转、多次反转、长时间停留）

状态：**假设与协议在评估前冻结**（冻结提交见 §8）。冻结后不得修改 §2–§5。来源：`docs/RETURN_TO_ORIGIN.md` G6。

## 1. 问题与依据

预注册 17 显示：按预测误差切换环境信念表的个体（regime）和按线索分账本的个体（cue），在 A/B/A（完全反转一次再回来）里比朴素学习器（plain）更能保留旧知识。本次问：这种保留在**训练时没见过的**变化模式里还成立吗？
- `half`：A/B'/A，B' 只反转随机一半种类（部分反转）；
- `abab`：A/B/A/B/A，多次反转；
- `long`：A/B/B/B/A，B 持续三个阶段（3600 tick），看旧知识能保留多久。

**不重新训练**：直接使用预注册 17 已冻结的 laya 基因组（`experiments/prereg/genome-hashes-17.json`，32 个：{plain,dual,regime,cue} × 种子 211–218），训练世界只有 3 阶段（A/B/A、A/B/C），所以这是分布外检验。开发期（2 个种子、8 个世界、测试方言、手工设定之外的开发期基因组，`--dev`）只用于排除明显不合理的阈值：half 下 regime 适应度比 plain 低约 0.07、节省高约 0.08；abab 节省高约 0.20、再学习高约 0.05、适应度高约 0.13；long 节省高约 0.45。

## 2. 世界（冻结）

留出方言池（主池 `heldout`，世界种子 610000 起）与事实方言池（次池 `factual`，620000 起）；K=6，危害封顶 1，无欺骗，每阶段 1200 tick，窗口 200 tick，8 个个体、立即反馈、无繁殖；`half` 世界长 3600 tick，`abab` 与 `long` 世界长 6000 tick。五个变体：half-off、abab-off、abab-true、long-off、long-true（true = 状态 A、B 各对应固定的一句线索；cue 学习器在 off 下无线索可用）。每个（基因组，变体）24 个新世界（各变体种子错开）。

指标：每阶段前两个窗口的“营养食物占比”E[p]（吃到营养 /（营养 + 有害）次数）；**节省** = 最后一个 A 阶段的 E − 第一个 A 阶段的 E；**再学习**（仅 abab）= 第二个 B 阶段的 E − 第一个 B 阶段的 E；适应度同前（0.7 存活 + 0.3 终态能量）。某阶段所有世界都没吃到任何食物（例如全部死亡）时该基因组的该指标记为 0；这使指标偏向“幸存者”，因此适应度（含存活）是并列的主指标。

## 3. 假设（冻结；单位 = 训练种子，8 个，按种子配对；主池 heldout，先验 laya）

- **H1**（部分反转不拖累，half-off）：regime 的适应度 − plain 的适应度 **> −0.03**（非劣效）。开发期约 −0.07，**预期可能不成立**。
- **H2**（half-off）：regime 的节省 − plain 的节省 **≥ +0.05**。
- **H3**（多次反转后仍保留，abab-off）：regime 的节省 − plain 的节省 **≥ +0.15**。
- **H4**（abab-off）：regime 的再学习 − plain 的再学习 **≥ +0.05**。
- **H5**（长时间停留后仍保留，long-off）：regime 的节省 − plain 的节省 **≥ +0.20**。
- **H6**（abab-off）：regime 的适应度 − plain 的适应度 **≥ +0.04**。
- **H7**（abab-true）：cue 的节省 − regime 的节省 **≥ +0.05**。
- **H8**（long-true）：cue 的节省 − plain 的节省 **≥ +0.20**。

## 4. 统计方法（冻结）

同预注册 17：符号翻转精确检验（8 个种子，最小 p = 1/256；H1 先减去 −0.03）；8 个假设 Holm（总 α = 0.05，只基于 p；并列按 H1…H8）；“成立” = Holm 拒绝且效应量条件满足。次要（描述性，不进入结论等级）：dual 与各学习器的全部节省、再学习、窗口轨迹；事实方言池；跨变体的适应度；遗忘与保留的权衡只用各学习器在 half / abab / long 的适应度与节省并列呈现。不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 5. 已知限制（预先声明）

1. 基因组在 3 阶段世界里训练，更长或更多次的反转是外推；regime 最多 4 张信念表，表满之后的行为是实现细节，不是“生命的记忆容量”。
2. 世界极简（6 种食物、整体或一半反转），不代表真实环境变化。
3. “吃到营养的占比”在幸存个体上计算，长世界里存活率下降会让该指标偏乐观或不可定义（记 0），所以同时看适应度。
4. 阈值是依据 2 个开发种子的判断；cue 没有开发期数据（H7、H8 阈值是预先判断）。
5. 评估池同此前（留出方言被多次评估；作者撰写；种子数小）。其余同预注册 17 §6。
