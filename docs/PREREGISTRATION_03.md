# 预注册 03：重复进化（3 个训练种子）的留出评估

状态：**冻结时写明（见 §7）**。冻结后不得修改 §2–§5；运行评估前必须先提交并推送本文件、哈希文件与评估脚本。

## 1. 要回答的问题

预注册 02（`PREREGISTRATION_02.md`）只用了 1 个训练种子，结论反映“这四个训练结果”。本次问：**H1（先验有用）、H2（增益来自语义）、H3（Laya 优于 VADER 词典）在不同的进化随机性下是否稳定？**

## 2. 被测系统（冻结）

4 个条件（laya / none / shuffled / vader）× 3 个训练种子（1、2、3）= 12 个基因组，训练设置完全相同（结构化个体 v2，40 代，种群 24，σ 0.25，学习率 0.1，K=32，危害封顶 4，延迟 20，每代 6 个训练世界），只有训练种子不同。种子 1 即预注册 02 的基因组；种子 2、3 为 2026-10-05/06 新跑（目录 `experiments/evo/st2-<条件>-0<种子>/final.json`）。12 个基因组的 SHA-256 在 `experiments/prereg/genome-hashes-03.json`，评估脚本在哈希不符时拒绝运行。训练后不得挑选或重训。

## 3. 评估世界（冻结）

- 留出方言词池（`pools/heldout.json`）与其 Laya 先验表（与预注册 02 相同）。K=32，营养与有毒各半，危害封顶 4，8 个个体，无繁殖。
- 4 个单元（欺骗 0 / 25% × 延迟 0 / 20），每单元 48 个**新世界种子**（160000 + 序号 + 单元序号 × 10000；预注册 02 用的是 150000 起，两者不重叠）。指标与 02 相同：适应度 = 0.7×存活占比 + 0.3×终态队列能量占比，并报告毒食物次数与存活率。

## 4. 假设与统计（冻结）

每个训练种子 r 内，把 4 个单元合并，按 (单元, 世界种子) 配对，差值 = laya_r − 对照_r（192 对）。

- H1：对照 = none；H2：对照 = shuffled；H3：对照 = vader。
- 对每个 (假设, 训练种子) 做配对自助法（10000 次，随机种子 20261006），得 95% CI 与单侧 p。
- **一个假设成立，当且仅当三个训练种子的单侧 p 都小于 Holm α**（交集检验：三个种子都显著，取最大 p；Holm 在 H1–H3 之间按最大 p 从小到大比较 α/3、α/2、α，总 α = 0.05），**三个种子的 CI 下界都 > 0**，并且（仅 H1）三个种子差值的平均 ≥ **+0.04**。
- 若某个假设不成立，其后（按最大 p 排序）的假设都不宣称成立。
- 其他一律为描述性：各单元均值、毒食物次数、存活率、每个训练种子的差值。不换比较、不换指标、不加种子、不重跑。

## 8. 结果（2026-10-06，一次性运行；原始输出 `experiments/evo/heldout-rep-eval-01/results.json`）

按冻结协议运行一次，哈希校验通过，未重跑。每个训练种子 192 对（4 单元 × 48 个新世界）。

| 假设 | 种子 1 | 种子 2 | 种子 3 | 最大 p（Holm α） | 结论 |
| --- | --- | --- | --- | --- | --- |
| H2 laya − shuffled | +0.147 [0.127, 0.169] | +0.012 [−0.016, 0.041] | +0.040 [0.013, 0.068] | 0.197（0.0167） | **不成立** |
| H1 laya − none | +0.150 [0.124, 0.174] | +0.011 [−0.017, 0.039] | +0.039 [0.014, 0.066] | 0.231（0.025） | **不成立** |
| H3 laya − vader | +0.015 [−0.005, 0.034] | −0.010 [−0.032, 0.012] | +0.031 [0.013, 0.049] | 0.816（0.05） | **不成立** |

各条件在 4 个单元的平均适应度（种子 1 / 2 / 3）：laya 0.500 / 0.486 / 0.513；none 0.351 / 0.475 / 0.473；shuffled 0.353 / 0.473 / 0.473；vader 0.486 / 0.495 / 0.482。分单元（种子 1 / 2 / 3）：
- inv0-delay0：laya 0.599 / 0.578 / 0.625；none 0.422 / 0.577 / 0.571
- inv0-delay20：laya 0.493 / 0.482 / 0.497；none 0.262 / 0.376 / 0.378
- inv25-delay0：laya 0.497 / 0.478 / 0.503；none 0.410 / 0.543 / 0.544
- inv25-delay20：laya 0.411 / 0.404 / 0.426；none 0.308 / 0.402 / 0.400

**如实结论**
1. 预注册 02 的“H1、H2 成立”**没有被三个训练种子稳定复现**。种子 1 的优势（约 +0.15）很大，种子 2、3 的无先验 / 打乱先验个体进化得好得多（种子 2 几乎追平，差 +0.011；种子 3 差 +0.039）。预注册 02 中 none/shuffled 偏低，主要是种子 1 的进化结果偏差，不能当作总体规律。
2. 按冻结的交集检验，三个假设均不宣称成立（H3 本来就未成立）。这是该协议下的正式结论，不改标准。
3. 以下为**事后、描述性**观察，不作确认性结论：
   - 有先验的个体**更稳定**：laya 三个种子的平均适应度在 0.486–0.513 之间，none 在 0.351–0.475 之间。先验的价值至少部分体现为“更少依赖进化运气”。
   - 在无延迟的单元里，种子 2、3 的无先验个体与 laya 几乎持平（如 inv0-delay0：0.577 / 0.571 对 0.578 / 0.625；inv25-delay0 反而略高）；在**延迟 20** 的单元里，laya 仍稳定领先约 +0.10（inv0-delay20：0.482 / 0.497 对 0.376 / 0.378）。即先验的增益主要出现在后果延迟的世界，这是需要新预注册才能确认的假设。
   - laya 与 vader 的差异小且方向不一致（种子 2 为负）。
4. 限制：评估使用的留出词池已在预注册 02 评估过一次（见 §5.1）；每个条件 3 个训练种子仍是小样本；差异在不同种子间的异质性本身是结论的一部分。
