# 共享生态实验：预定问题、对照和判据

登记于 2026-09-30，新的留出环境尚未运行。原始配置为 `experiments/ecology/config/heldout-01.json`；本文件不将预定任务写成已完成结果。

## 开发与训练

开发难度的 50 个规则/随机运行支持选择 moderate-patches：规则能生存，随机策略明显受限。随后训练种子为 313、317、331，8 个初始个体，3600 步，每 1200 步改变隐藏资源分布 A/B/A。关闭繁殖与变异，死亡保留，不复活、不只选幸存者。固定 Laya、有限记忆、无 Laya、初始冻结和规则组成同环境对照。

路线 B 使用 324 维局部输入和独立 MaskablePPO，actor/critic 各 32 隐单元，32 次动作反馈一批、4 个 epoch、minibatch 16、学习率 0.001。时间折扣按真实模拟子步计算，gamma 0.998、GAE lambda 0.995；奖励仍为真实能量差除以 10，死亡额外扣 1。参数、优化器、经验和 RNG 逐个体隔离。Laya 不训练。

融合比较固定为两种：偏好特征（主路线当前默认）和 `log(max(prior,0.02)) + 2*tanh(residual_logits)`。两者参数量、训练种子和交互时限一致；无 Laya 时偏好输入为零，残差分布使用均匀基底。残差组属于预先声明的额外比较，不从留出结果挑选最好版本后改称主要假设。

## 新留出评估

训练种子 313/317/331 分别配对未使用过的世界种子 1009/1013/1019。每个世界 2700 步，每 900 步切换 A/B/A，检验未参与训练的资源随机安排和变化时刻。身体参数保持相同，不声称验证任意迁移。

所有学习策略冻结参数、优化器和训练计数；各组保留相同地点记忆更新。每个原始个体（含在训练中死亡者）从其最后检查点进入新的独立评估世界，并以 `heldout_seed*100 + sorted_cohort_index` 重置采样随机流。初始化冻结对照使用同一训练种子的原始权重，也重置为相同评估随机流。此处是新评估任务，不是把在线死亡个体复活后继续训练。

预定组：特征融合训练后 / 匹配初始化冻结、无 Laya 训练后、特征融合遮蔽记忆输入、残差融合训练后 / 匹配初始化冻结、规则、固定 Laya 当前观测、固定 Laya 有限记忆。记忆消融只遮蔽网络和 Laya 的输入，保留真实世界记忆及原始记录；不是暗改世界。

主要学习信号沿用 M0 的探索性门槛：初始全队列平均未折扣回报差至少 0.1、总死亡数不增加、至少 2/3 配对世界回报差为正。Laya 的贡献使用同一门槛比较训练后 B 与无 Laya。三个世界不足以得出总体显著性；必须同时报告各个种子、负差异、死亡和无收益。

次要指标包括存活时长比例、全队列能量、采食、低能量时间、移动能耗、无效往返，以及 A/B/A 各阶段的变化。恢复定义为阶段切换后同一个体达到至少 25% 能量并连续保持十个决策边界；未恢复、死亡或到时限的个体分别标记右删失，不拿幸存者的平均恢复速度替代全队列结果。边界采样的能量和恢复测量明确其十步精度，不冒充逐子步轨迹。

返回 A 的表现包含原有世界资源、竞争与存活差异，只作为在线保留/恢复诊断，不能单凭它推断神经网络遗忘。冻结的留出对照才用于参数学习收益判断。

## 证据与成本

每轮保留真实请求、Laya 输入输出、策略输入、提案、更新哈希、实际反馈与完整世界快照。每 32 轮及运行末尾保存完整学习检查点。文件同时记录源码副本与哈希、模型固定版本、实际设备和耗时；不以种子代替在线推理记录。

批量执行器只合并固定 Laya 的推理，不共享策略或经验。相同合成先验下，三个世界的分批/逐世界运行已用真实 TS + PPO 验证参数和世界完全一致；该测试不计为真实 Laya 证据。真实批量执行仍单独记录原始模型响应，不能据此承诺不同批大小下 GPU 浮点逐位一致。

工程成功与收益信号分别验收。若收益未达门槛，交付完整负结果与原因分析，保持路线 B；不自动转到直接微调 Laya 或其他未授权扩展。
