# 预注册 06：匹配训练与层次信念（W5b）——先验的价值能否在匹配的世界里恢复，层次信念能否在强欺骗下挽回先验

状态：**假设与协议在训练开始前冻结**（冻结提交见 §10；48 个基因组的哈希在训练完成后、评估前追加）。冻结后不得修改 §2–§6。

## 1. 来源与动机

预注册 04（`PREREGISTRATION_04.md` §10）显示：先验的价值取决于世界。后果延迟 40 且欺骗 0.25 时 laya 比 none 高 +0.096（8/8 种子）；没有延迟时 none 更好（−0.09～−0.14，8/8）；延迟 40 且欺骗 0.40 时 −0.031。但训练是在延迟 20、欺骗至多 0.25 的混合世界里进行的，评估包含训练未见的世界。两个问题因此无法回答：

1. “先验有害”是不是**训练与评估世界不匹配**造成的？（在匹配的世界里进化，是否能消除延迟 0 世界里的劣势、保持延迟 40 世界里的优势？）
2. 在 `structured-hier.ts` 中实现的**层次信念**（相似描述共享经验，W5b）能否在强欺骗（0.40）下挽回先验的价值？

## 2. 因素与被测系统（冻结）

2×2×2 因素设计，每个格 6 个训练种子（21–26），共 48 次独立进化：

| 因素 | 水平 |
| --- | --- |
| 先验 | `laya`（固定 Laya 对描述的缓存判断）/ `none`（无先验） |
| 信念结构 | `flat`（结构化个体 v2，9 个基因）/ `hier`（加 share、thr 两个基因，共 11 个，嵌入见 `experiments/evo/laya-embed-v1`） |
| 训练 / 评估制度 | `d0`（所有训练世界与评估世界的后果延迟 = 0）/ `d40`（全部延迟 = 40） |

训练设置（所有格相同，除上表因素）：40 代，种群 24，σ 0.25，学习率 0.1，每代 6 个训练世界（训练方言词池 `train`），K=32，危害封顶 4，**所有训练世界使用该制度的延迟（`--delayAll on`）**，欺骗按 0.25 / 0.40 循环（`--inversions 0.25,0.4`，不含无欺骗世界）。训练种子 s 在各格间共享（相同的进化噪声序列），因此按 s 配对。命令模板：

```
node packages/evo/semantic-evolve.ts experiments/evo/f6-<先验>-<flat|hier>-<d0|d40>-<s> \
  --prior <laya|none> --learning on --agent structured [--hier on] --pool on --K 32 --harmCap 4 \
  --delay <0|40> [--delayAll on] --inversions 0.25,0.4 --worlds 6 --generations 40 --pop 24 \
  --sigma 0.25 --lr 0.1 --seed <s> --workers 1
```

训练后不得挑选、重训或剔除任何基因组。

## 3. 评估世界（冻结）

- **主池**：留出方言 `heldout`（4000 条；该池已在预注册 02–04 评估过，只看汇总，见 §7）。**次池**：事实方言 `factual`（4000 条，需要世界知识的描述；先前只做过先验质量评估，没有评估过个体）。两个池的 Laya 先验表与嵌入都是缓存的、只依赖文本。
- 每个训练 / 评估制度只在与其训练匹配的延迟下评估：`d0` 个体在延迟 0，`d40` 个体在延迟 40；欺骗 {0.25, 0.40} 两个单元，每单元 32 个新世界（主池世界种子 180000 起，次池 190000 起，各单元与制度错开）。K=32，危害封顶 4，8 个个体，无繁殖。
- 指标：适应度 = 0.7×存活占比 + 0.3×终态队列能量占比；同时报告毒食物次数与存活率。

## 4. 假设（冻结，仅在主池上确认）

分析单位是训练种子（6 个，按种子配对）。对每个训练种子，先把评估世界取均值，再做差：

- **H1（匹配训练消除延迟 0 世界里的劣势，非劣效）**：制度 d0，flat，欺骗 {0.25, 0.40} 平均：laya − none 的 6 个种子平均差 **> −0.04**（预注册 04 中同一比较是 −0.085 与 −0.136）。检验：把差值加 0.04 后做单侧符号翻转精确检验。
- **H2（匹配训练保持延迟 40 世界里的优势）**：制度 d40，flat，欺骗 {0.25, 0.40} 平均：laya − none 的平均差 **≥ +0.04**，符号翻转精确检验。
- **H3（层次信念在强欺骗下挽回先验）**：欺骗 0.40 单元，对 d0 与 d40 两个制度取平均：（laya，hier）− （laya，flat） 的平均差 **≥ +0.03**，符号翻转精确检验。

## 5. 统计方法（冻结）

- 符号翻转精确检验：6 个种子，2^6 = 64 种符号，p = 符号翻转后均值 ≥ 观测均值的比例（最小 p = 1/64 = 0.0156）。
- Holm 逐步检验**只基于 p 值**：按 p 从小到大（并列时按 H1、H2、H3 的顺序）比较 α/3、α/2、α（总 α = 0.05）；一个假设在 Holm 中未被拒绝，其后的都不拒绝。“成立”= Holm 拒绝 **且** 该假设自己的效应量条件满足。效应量条件不满足**不会**阻断其他假设（此处明确规定，以避免预注册 04 中并列 p 与效应量条件混用的歧义）。
- 次要（描述性）：完整 2×2×2 格均值；层次信念对 none 的效应；各欺骗强度、各制度的 laya − none；毒食物次数、存活率；次池（事实方言）上同样的 H1–H3 统计量，**不作确认性结论**。
- 不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 6. 已知限制（预先声明）

1. 6 个训练种子是小样本；符号翻转检验在 6 个种子下只有当 6 个种子全部同向时才能达到 Holm 的 α/3；这很保守。
2. 训练只用训练方言；评估方言与之不同，所以每个检验同时包含“跨方言泛化”。
3. 嵌入只在训练方言池上拟合 PCA，评估时投影；层次信念的收益取决于嵌入在新方言上的相似度结构。
4. 层次信念使用 Laya 编码器的缓存向量（系统 1 的另一路输出），不是纯粹的“个体学习”；hier 与 flat 的差异包含了 Laya 嵌入的贡献，这与“none，hier”条件（只有嵌入、没有判断先验）一起解读。
5. 其余同预注册 02 §8。
