# 预注册 17：一生内的保留与恢复（A/B/A）、全新规则（A/B/C）与环境线索

状态：**假设与协议在训练开始前冻结**（冻结提交见 §9；64 个基因组的哈希在训练完成后、评估前追加）。冻结后不得修改 §2–§5。来源：项目初心（`docs/RETURN_TO_ORIGIN.md`）与开发期探针（§1）。

## 1. 动机与开发期依据（非确认性）

初心问题：同一个生命能否在一生中学会新方法、环境变化后继续适应，并在旧环境返回时保留或恢复已有能力？开发期探针（`packages/evo/aba-probe.ts`，手工基因）与 2 个种子的小规模进化（有先验，`experiments/evo/dev-aba-eval-01`）显示：完全反转的世界里，普通学习器（plain）回到旧环境时反而更差（“节省” −0.11、−0.06，旧知识被 B 段改写），快慢两套信念（dual）约为 0，环境分段记忆（regime）为正（+0.17、+0.22）；regime 的适应度比 plain 高约 0.08；在全新规则（A/B/C）下 regime 与 plain 的适应度差约 −0.005。无先验（none）的进化与线索键控记忆（cue）没有做开发期进化试训（机器被其他项目占满，已停止）；cue 只做了烟雾测试。

## 2. 被测系统与训练（冻结）

**世界**：K=6 种食物（一半营养、一半有毒），危害封顶 1（无致命），无欺骗，每个世界 3600 tick，分三段各 1200 tick；个体 8 个，立即反馈，无繁殖。`drift` 多状态日程：状态 A = 原样；B = 所有种类的影响取反；C = 随机一半的种类取反（既不是 A 也不是 B，但与二者各有一半相同）。**A/B/A** 世界的日程是 A→B→A；**A/B/C** 世界是 A→B→C。训练世界为二者交替（每代 6 个世界：3 个 A/B/A + 3 个 A/B/C），**环境线索为真实**：状态 A、B、C 各对应固定的一句可见句子（在观测的 season 字段）。

**学习器**（均为结构化个体 v2 的变体，Laya 固定，先天 = 基因组，后天 = 一生内的信念）：
- `plain`：9 个基因，对每个描述词一个遗忘平均的信念；忽略线索；
- `dual`：+4 个基因（快、慢遗忘，误差滑动速率，锐度）：两套信念按预测误差加权；忽略线索；
- `regime`：+3 个基因（新开阈值 theta、速率、切换余量）：最多 4 套环境信念表，按预测误差切换 / 新开；忽略线索；
- `cue`：9 个基因，信念按（线索句子，描述词）保存；不理解线索含义，只作标签。
**先验** {laya, none} × 4 学习器 × 8 个**新**训练种子（211–218）= 64 次独立进化（训练世界随种子变化）。训练设置：40 代，种群 24，σ 0.25，学习率 0.1，适应度同前（0.7 存活 + 0.3 终态能量）。

```
node packages/evo/semantic-evolve.ts experiments/evo/f17-<laya|none>-<plain|dual|regime|cue>-<s> \
  --prior <laya|none> --learning on --agent structured --learner <...> --pool on --K 6 --harmCap 1 --inversions 0 \
  --driftAll on --driftFraction 1 --driftPhase 1200 --driftPattern mix --driftCue true --worldSeeds vary \
  --worlds 6 --generations 40 --pop 24 --sigma 0.25 --lr 0.1 --seed <s> --workers 1
```
（脚本 `scripts/run-f17.sh`。）训练后不得挑选、重训或剔除任何基因组。

## 3. 评估世界（冻结）

留出方言池（主池 `heldout`，世界种子 510000 起）与事实方言池（次池 `factual`，520000 起）；6 个世界变体：{A/B/A, A/B/C} × 线索 {off 不显示, true 真实, random 每阶段随机一句，与状态无关}；每个（基因组，变体）32 个新世界（各变体种子错开）；盲规则同批评估。窗口 200 tick。指标：窗口内“营养食物占比”（吃到营养 /（营养 + 有害）次数）；**早期** = 每段前两个窗口，**晚期** = 每段后两个窗口；**节省** = 第三段早期 − 第一段早期（A/B/A 世界里为“旧环境返回的收益”）；适应度同前；毒食物次数。

## 4. 假设（冻结；分析单位是训练种子，8 个，按种子配对；主池 `heldout`，有先验 laya）

- **H1**（只靠预测误差推断环境，A/B/A、线索 off）：regime 的节省 − plain 的节省 **≥ +0.15**。
- **H2**（线索让保留变得容易，A/B/A、线索 true）：cue 的节省 − plain 的节省 **≥ +0.20**。
- **H3**（明说比推断更快，A/B/A、线索 true）：cue 的节省 − regime 的节省 **≥ +0.05**。
- **H4**（全新规则下不被旧知识拖累，A/B/C、线索 off）：regime 的适应度 − plain 的适应度 **> −0.03**（非劣效）。
- **H5**（误导的线索有代价，A/B/A、线索 random）：plain 的适应度 − cue 的适应度 **≥ +0.02**。
- **H6**（保留带来整体收益，A/B/A、线索 off）：regime 的适应度 − plain 的适应度 **≥ +0.04**。

阈值依据：开发期 H1 差约 +0.28、H6 差约 +0.08、H4 差约 −0.005（2 个种子，有先验，线索未参与训练）；取显著小于观测的值以免过度乐观。H2、H3、H5 没有开发期进化数据，阈值是预先的判断。

## 5. 统计方法（冻结）

符号翻转精确检验（8 个种子，p = 符号翻转后均值 ≥ 观测均值的比例，最小 1/256；H4 先把差值减去 −0.03，即非劣效检验）；6 个假设用 Holm（总 α = 0.05；步长 α/6 … α；并列按 H1…H6 的顺序，**只基于 p 值**）；“成立” = Holm 拒绝且效应量条件满足。次要（描述性）：无先验（none）的全部比较（先天 / 后天 / Laya 先验分解：laya − none 在各学习器、各变体下的差）；事实方言；各学习器的窗口轨迹；节省在 dual 与 plain 之间的差；A/B/C 世界里 C 段早期占比；其他线索变体下的所有两两比较；进化出的基因（theta、margin、fast/slow 等）。不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 6. 已知限制（预先声明）

1. 世界极简：6 种食物、整体反转；C 是 A 与 B 的混合（一半同 A，一半同 B），不是完全陌生的规则。
2. “节省”还包含与种类无关的一般学习（例如学会“吃了会有后果”）；完全反转使这一成分较小，但不为零，所以只比较学习器之间的差，不把绝对值当作“记住了多少”。
3. 线索是 3 句作者撰写的句子；cue 学习器把它当字面标签，因此对“随机线索”敏感，对“含义”无反应；这不是对线索理解的检验。
4. dual、regime、cue 各是该思路的一种实现，未经调参；regime 的表数上限为 4。
5. 无先验与 cue 学习器没有开发期进化数据；H2、H3、H5 的阈值是预先判断。
6. 评估池同此前（留出方言被多次评估；作者撰写；单一模拟生态；种子数小）。
7. 其余同预注册 02 §8。
