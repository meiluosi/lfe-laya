# 预注册 02：Laya 先验在进化个体上的留出评估

状态：**已冻结（2026-10-05，冻结提交见 §10）**。原“草稿”说明：冻结的含义：本文件、`experiments/prereg/genome-hashes.json` 与评估代码一起提交并推送（git 提交即时间戳），之后才允许运行 `packages/evo/heldout-eval.ts --dialect heldout`。冻结后协议不得修改；若发现缺陷，必须公开记录并说明如何处理（见 §9）。

## 1. 要回答的问题

在一个“试错代价高”的世界里（致命食物、延迟后果、线索可能被欺骗），**固定 Laya 对描述文字的判断（先验）**是否让**进化出的个体**活得更好？这个增益是否来自语义本身，而不是任何带噪的信息，也不是任何简单的情感词典能做到的？

背景与此前的结论：见 `docs/EVOLUTION.md` 5.5–5.10、`docs/WORLD_COMPLEXITY.md` 14。手写控制器上的闸门 G3–G5 失败，原因是手写阈值不适合 AUC≈0.88 的先验，所以真正的检验必须在**由进化决定如何使用先验**的个体上做。

## 2. 为什么这是“留出”

| 数据 | 用途 | 状态 |
| --- | --- | --- |
| 训练方言（`pools/train.json`，12000 条） | 进化个体的训练世界；先验表 `laya-prior-v2/train.jsonl` | 已用于训练 |
| 测试方言（`pools/test.json`，4000 条） | 开发：设计、闸门、先验质量、进化中的周期性报告 | **已被反复查看，属于开发集，不作为确认性证据** |
| **留出方言**（`pools/heldout.json`，4000 条；野外笔记体） | **本预注册的确认性评估** | 盲写：写作时未看任何实验结果，也未对照 Laya 调整；与训练、测试方言**没有任何完全相同的短语**，词汇共享约 30%（多为功能词）；其 Laya 先验表只对**文本**计算，冻结前未用标签计算任何指标或运行任何控制器 |

留出评估的世界种子（150000 起）在冻结前从未被任何运行使用。

## 3. 被测系统（冻结）

进化个体：结构化个体 v2（规则骨架 + 9 个基因；`packages/evo/structured.ts`），四个条件，各在训练方言世界里进化 40 代（每代 6 个世界，种群 24，种子 1；K=32，危害封顶 4，半数世界延迟 20，含 25% 欺骗），训练过程只使用训练方言与训练种子；留出评估前不得再训练或挑选。

| 条件 | 先验来源 | 基因组文件 |
| --- | --- | --- |
| `进化·laya` | 固定 Laya 对描述的缓存判断 | `experiments/evo/st2-laya-01/final.json` |
| `进化·none` | 无先验（只靠个体经验与好奇心） | `experiments/evo/st2-none-01/final.json` |
| `进化·shuffled` | 打乱的 Laya（保持边缘分布，破坏语义对应） | `experiments/evo/st2-shuffled-01/final.json` |
| `进化·vader` | VADER 情感词表（独立来源，MIT） | `experiments/evo/st2-vader-01/final.json` |

四个基因组文件的 SHA-256 记录在 `experiments/prereg/genome-hashes.json`；评估脚本在哈希不符时拒绝运行。

对照与参考（手写，不进入确认性假设）：盲规则、手写无先验学习者、手写 Laya 自适应、手写 VADER 自适应（延迟信用窗口均为 50）、预言机（读取隐藏真值，只度量上限）。

## 4. 评估世界（冻结）

- 来源：留出方言词池；K=32 种食物，营养与有毒各半；危害封顶 4（致命种类存在）；8 个个体，无繁殖；其余参数同训练（`SCENARIOS.semantic`）。
- 四个单元（每个 48 个种子，种子 = 150000 + 序号 + 单元序号 × 10000）：

| 单元 | 欺骗（真实影响与描述相反的比例） | 延迟（模拟步） |
| --- | --- | --- |
| inv0-delay0 | 0 | 0 |
| inv0-delay20 | 0 | 20 |
| inv25-delay0 | 0.25 | 0 |
| inv25-delay20 | 0.25 | 20 |

- 指标：适应度 = 0.7 × 幸存时间占比 + 0.3 × 终态队列能量占比（与训练一致）。同时报告毒食物次数与存活率。

## 5. 确认性假设（冻结）

按 (单元, 种子) 配对，把四个单元合并（共 192 对）。差值 = 前者 − 后者，适应度尺度。

- **H1（先验有用）**：`进化·laya − 进化·none` 的点估计 ≥ **+0.04**，且 95% 置信区间下界 > 0。
- **H2（增益来自语义）**：`进化·laya − 进化·shuffled` 的 95% 置信区间下界 > 0。
- **H3（Laya 的广度）**：`进化·laya − 进化·vader` 的 95% 置信区间下界 > 0。

## 6. 统计方法（冻结）

- 按种子（含单元内配对）自助法重采样 10000 次，固定随机种子 20261005；报告 95% 置信区间与单侧 p（重采样差值 ≤ 0 的比例）。
- 三个假设用 Holm 逐步校正（总 α = 0.05，按单侧 p 从小到大依次比较 α/3、α/2、α）；一个假设不成立后，后续假设都不宣称成立。
- “假设成立”须同时满足：Holm 条件、置信区间下界 > 0，以及 H1 的效应量下限。
- 不成立或模糊时如实报告，不换比较、不换指标、不再抽种子。

## 7. 次要与探索性分析（不作确认性结论）

- 各单元分别的差值；毒食物次数、存活率。
- `进化·laya − 手写 Laya 自适应`、`进化·laya − 手写无先验学习者`、`手写 Laya 自适应 − 手写 VADER 自适应`。
- 先验质量（留出池前 1500 条的区分营养 / 有毒的 AUC）：Laya、VADER、作者自写通用词典、训练方言词典、打乱的 Laya。该指标需要标签，**只在最终评估时与世界评估一起计算**。
- 手写控制器的闸门 G1、G2、G6 作为背景（G3–G5 在手写控制器上已知不适用，见 §1）。

## 8. 已知限制（预先声明）

1. 方言是我撰写的（三套，作者相同），生成器与词表独立于 Laya 的任何输出，但仍属“作者写的自然语言”；留出方言不等于真实开放世界的语言。
2. 世界是模板化的食物场景；先验只用于对描述的“能不能吃”判断。
3. 进化只用 1 个训练种子序列、每个条件 1 次运行；没有对进化随机性的重复，因此确认性比较反映的是“这四个训练结果”，不是“该方法的总体”。
4. 手写控制器的阈值为开发期选定。
5. 测试方言被用于开发，其结果不构成确认性证据。

## 9. 偏离与缺陷的处理

冻结之后：(a) 不得修改本文件的 §3–§6；(b) 评估脚本只允许修复**不改变协议语义**的缺陷（如崩溃），并必须在 `docs/EVOLUTION.md` 与本文件末尾追加说明；(c) 若发现影响结果的缺陷，公开说明、保留首次运行的原始输出，并在重跑时同时报告两次结果；(d) 评估只运行一次，不因结果不理想而重复。
