# 预注册 21（G11c）：贝叶斯环境推断 + LLM 句对判断作传感器，在“线索措辞每阶段都改写”的世界里与 regime 对等比较

状态：**假设与协议在训练开始前冻结**（冻结提交见 §9；32 个基因组的哈希在训练完成后、评估前追加）。冻结后不得修改 §2–§5。来源：`docs/DESIGN_G11_DUAL_SYSTEM.md` §13–§17。

## 1. 动机

G11 两轮探针（`g11-probe-01/02`）显示：让 LLM 在意外时直接决定“切表 / 新开表”没有保留收益。用户指出 LLM 读到带噪声的经历会被误导，应引入贝叶斯类理论辅助。G11b 探针（`g11b-probe-01`）用手搓的数值引擎 + LLM 传感器，方向有利但未达判据；审查发现该引擎有统计上的缺陷（固定方差而非后验预测方差、硬 MAP 更新、新环境预测的任意假设、手设参数、无软分配 / 模型平均）。本预注册用**重写的贝叶斯环境推断学习器**（`packages/evo/structured-benv.ts`：共轭正态模型、后验预测边缘似然、前向滤波、软责任更新、贝叶斯模型平均；基因含 σ、换环境概率 h、新环境份额 ν、传感器可靠度 rel、边界换环境概率 hb，由进化决定）回答：**把语言证据（缓存的 LLM 句对判断）并入严格的贝叶斯推断后，能否在线索措辞每阶段都改写的世界里取得保留，并与 regime 对等比较。**

## 2. 被测系统与训练（冻结）

- **传感器 = 缓存的 LLM 判断**：`packages/evo/cue-sim.json`——`deepseek-flash`（思考关闭，由 DeepSeek-V4.1-Flash-1017 提供服务）对 36 条线索句（`cues.json` 状态 A/B/C 的训练句 + 评估句，作者撰写）所有 630 个句对的“是否同一类条件”判断（两种顺序平均），提示与探针 C 完全一致（`experiments/evo/g11c-sensor/llm-log.jsonl`，1500 次调用，构建脚本 `packages/evo/build-cue-matrix.ts`）。同状态句对均值 0.943（最小 0.60），不同状态句对均值 0.044（最大 0.25）。训练与评估都查这张表：同步、免费、可严格回放；个体看不到状态标签（标签只在 cue-sim.json 里供对照条件与度量使用）。
- **新增世界线索模式 `paraphrase`**：同一状态每次出现换一句不同措辞（不与该状态此前用过的重复），字面标签因此不再可靠。
- 学习器：`benv`（14 基因 = plain 的 9 个 + σ、h、ν、rel、hb；传感器开）、`benv-off`（同一学习器，传感器关：消融）。**训练 = 32 次独立进化：{bayes, benv-off} × 新一批训练种子 221–236 ×先验 laya**，世界与参数同预注册 17（K=6 完全反转，A/B/A 与 A/B/C 交替，训练方言池，40 代，种群 24，σ 0.25，学习率 0.1，世界种子随训练种子变化），**只改线索为 `paraphrase`**。运行脚本 `scripts/run-f21.sh`。训练后不得挑选、重训或剔除。
- **对照基因组**：plain、regime、cue 直接用预注册 20 已训练并冻结的 f20 基因组（种子 221–236，同一批训练种子，按种子配对；它们在 `true` 线索的世界里训练，plain 与 regime 不读线索，cue 学习器按字面线索分表）。评估须先校验 f20 与 f21 两份哈希（`experiments/prereg/genome-hashes-20.json`、`genome-hashes-21.json`）。
- 开发期（非确认性）：手工参数（σ 0.7、h 0.02、ν 0.3、rel 0.9、hb 0.5）的 benv，在开发池 `test`、开发期基因组 plain 201 上，A/B/A（paraphrase）：benv 节省 +0.124（plain −0.136，regime +0.095），适应度 .862（plain .783，regime .864）；benv-off ≡ plain；预言机传感器 .857；打乱传感器 .799；30% 取反 .817；A/B/A/B/A：benv 节省 +0.177 对 plain −0.046。更小规模的 f17 开发基因组（种子 211、212，6 个世界）里 cue 学习器在 paraphrase 世界适应度高（.92–.97，因为每次句子一变就是一张新表）但节省低（+0.06 / +0.13），benv 节省 +0.23 / +0.25。

## 3. 评估世界（冻结）

- 主池 `mushroom`（独立来源，见预注册 20 §3；该池的 Laya 先验 AUC 0.505，即先验无区分力）；次池 `heldout`（连续性）。
- 世界：K=6，危害封顶 1，无欺骗，8 个个体，立即反馈，无繁殖，每阶段 1200 tick，窗口 200 tick；变体：`aba-para`（A/B/A，线索 paraphrase）、`abab-para`（A/B/A/B/A，线索 paraphrase）。每个（基因组，池，条件，变体）24 个新世界（世界种子：mushroom 720000 起、heldout 730000 起，变体错开）。
- 评估条件：plain、regime、cue、benv-off、**benv**（缓存的 LLM 传感器）、**benv@oracle**（同一基因组，传感器 = 作者的状态标签，只作上限度量，个体不可得）、**benv@shuffled**（同一基因组，句子序号随机置换，破坏语义对应）、**benv@wrong30**（同一基因组，30% 的句对判断被取反，按句对哈希确定）。
- 指标同预注册 18/20：早期 = 每段前两个窗口的营养食物占比；节省 = 最后一个 A 段早期 − 第一个 A 段早期；适应度 0.7 存活 + 0.3 终态能量；某段早期所有世界都没吃到食物记 0。

## 4. 假设（冻结；单位 = 训练种子，16 个，按种子配对）

- **H1**（mushroom、`aba-para`）：benv 节省 − plain **≥ +0.15**。
- **H2**（mushroom、`aba-para`）：benv 适应度不比 regime 差超过 0.03，即 benv − regime **> −0.03**（非劣效）。
- **H3**（mushroom、`aba-para`）：benv 节省 − benv-off **≥ +0.15**（传感器贡献）。
- **H4**（mushroom、`aba-para`）：benv 适应度 − benv@shuffled **≥ +0.03**（读懂语言有用，而不是“任何线索变化”都有用）。
- **H5**（mushroom、`aba-para`）：benv@wrong30 适应度 − plain **≥ +0.02**（传感器 30% 读错仍不比不用差）。
- **H6**（mushroom、`abab-para`）：benv 节省 − plain **≥ +0.10**。
- **H7**（heldout、`aba-para`，连续性）：benv 节省 − plain **≥ +0.15**。
- **H8**（mushroom、`aba-para`）：benv 适应度不比 benv@oracle 差超过 0.03，即 benv − benv@oracle **> −0.03**（LLM 传感器接近预言机）。
- **H9**（mushroom、`aba-para`）：benv 节省 − cue **≥ +0.08**（对比按句子字面分表的记忆）。

## 5. 统计方法（冻结）

符号翻转精确检验（16 个种子；H2、H8 先减去 −0.03）；9 个假设 Holm（总 α = 0.05，只基于 p，并列按 H1…H9）；“成立” = Holm 拒绝且效应量条件满足。次要（描述性）：全部单元的适应度与节省（含 K 与 `abab-para`、heldout 池、cue 与 benv-off 的表现）。不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 6. 已知限制（预先声明）

1. 传感器是 LLM 对作者撰写的 36 条线索句的判断，探针 C 与矩阵显示几乎完美区分（偏容易）；本预注册不说明 LLM 理解“环境变了对食物意味着什么”，只检验“把语言证据并入贝叶斯推断是否带来保留”。
2. benv 与 benv-off 在 paraphrase 世界里训练，plain、regime（f20）在 `true` 线索世界里训练，cue 在 `true` 线索里训练、评估在 paraphrase 世界里是分布外（它会因字面不匹配而每阶段开新表）；plain 与 regime 不读线索，所以训练线索不影响它们，但这不是严格的同分布比较，须在结果里说明。
3. 传感器缓存让评估同步、可回放，但也意味着评估没有新的 LLM 调用；换一个模型或提示，传感器的可靠度会不同。
4. mushroom 池上 Laya 先验无区分力（AUC 0.505），个体只能靠经验；heldout 池是已被多次评估的作者方言。
5. 世界仍是模拟小世界，K=6，种子 16；线索句是作者撰写的天气句。

## 10. 结果（2026-10-29，一次性运行；原始输出 `experiments/evo/bayes-eval-01/`：`results.json` 汇总、`seed-<种子>.json` 逐种子、`run-<种子>.out` 日志）

| H9 benv 节省 − cue（≥ +0.08） | **+0.176** | ≈ 0 | 16/16 为正 | 成立 |

16 个种子平均（适应度 / 节省；mushroom，aba-para → abab-para）：plain .730 / −.11 → .636 / −.18；regime .809 / +.11 → .767 / +.05；cue .897 / +.07 → .888 / −.01；benv-off .731 / −.11 → .646 / −.18；**benv .904 / +.25 → .902 / +.24**；benv@oracle .905 / +.25 → .901 / +.24；benv@shuffled .715 / −.09 → .518 / −.09；benv@wrong30 .738 / +.02 → .585 / +.04。heldout 池方向一致（benv .954 / +.25 → .906 / +.28）。

**读法**：
1. **把语言证据并入严格的贝叶斯推断后，在“线索措辞每阶段都改写”的世界里，进化出的 benv 在保留上明显胜过 regime、cue 和 plain**（节省 +0.25 / +0.24，对 plain 的差 +0.35 / +0.42，16/16 种子同向），适应度（.90）也高于 regime（.81）；LLM 传感器几乎等同于预言机（差 −0.0005）。
2. **去掉传感器（benv-off）完全回到 plain 的水平**（.731 对 .730），传感器是全部收益的来源；**打乱传感器适应度掉到 .72（abab 里 .52）**，说明是“读懂语言”，不是“有线索就行”。
3. **cue 学习器（按句子字面分表）适应度也高（.90）但节省低（+0.07 / −0.01）**：每次句子一变就新开一张表，等于“每个阶段重新学一遍”，适应度高但没有保留旧知识。
4. **读错的代价（H5 不成立）**：传感器 30% 的句对判断被取反时，benv 的适应度只比 plain 高 +0.008（7 个种子为负），没有达到“仍比不用线索好 0.02”的阈值；abab 里甚至低于 plain（.585 对 .636）。进化出的 benv 基因是在**传感器几乎完美**的训练世界里进化的，没有任何理由学会怀疑（对应预注册 22 / G13 的“进化史应含不可靠线索”）。
5. 限制：见 §6；另外，本预注册里 benv 的参数是进化出的，但 regime、plain 来自预注册 20 的训练（不同的线索训练分布），不是严格同分布比较；传感器是缓存的 LLM 判断，评估没有新的 LLM 调用；线索句是作者撰写的（36 句），环境只有两个状态的交替。
