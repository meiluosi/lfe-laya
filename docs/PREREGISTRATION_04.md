# 预注册 04：先验在“后果延迟更长、欺骗更强”的世界里是否更有价值、更稳定

状态：**假设与协议在训练开始前冻结**（冻结提交见 §9；训练出的 24 个基因组的哈希在训练完成后、评估前追加冻结）。冻结后不得修改 §2–§6。

## 1. 来源与动机

预注册 03 显示：预注册 02 的大效应（laya 对 none +0.15）没有被 3 个训练种子稳定复现，但出现了两个**事后**观察：
(a) 有先验的个体结果更稳定（laya 三种子 0.49–0.51，none 0.35–0.48）；(b) 增益主要出现在后果延迟的世界（延迟 20 的单元仍领先约 +0.10），无延迟时种子 2、3 的无先验个体几乎追平。
本次用**全新的训练种子**（11–18）把这两个观察变成预先声明的假设。预注册 03 的结论不变，不据此调整本次的任何阈值之外的东西。

## 2. 被测系统（冻结）

3 个条件 × 8 个训练种子（11–18）= 24 次独立进化，设置与预注册 02/03 完全相同，只有训练种子不同：结构化个体 v2，40 代，种群 24，σ 0.25，学习率 0.1，K=32，危害封顶 4，训练世界延迟 20，每代 6 个训练世界（训练方言词池，含 25% 欺骗的混合）。

| 条件 | 先验来源 |
| --- | --- |
| laya | 固定 Laya 对描述的缓存判断 |
| none | 无先验 |
| vader | VADER 情感词表（独立来源） |

目录 `experiments/evo/st2-<条件>-<种子>/final.json`（种子为两位数 11–18）。**不含打乱先验条件**（03 中它与 none 几乎没有区别；语义来源的检验留给 W5 的新语义）。训练结束后不得挑选、重训或剔除任何基因组；任何进化崩溃必须保留并计入结果。

## 3. 评估世界（冻结）

- 留出方言词池与 Laya 先验表（同 02/03；该词池已被评估过两次，只看汇总，未用于调参，见 §7）。K=32，危害封顶 4，8 个个体，无繁殖。
- 4 个单元：延迟 {0, 40} × 欺骗 {0.25, 0.40}。延迟 40 比训练时（20）更长，欺骗 0.40 比训练时（最高 0.25）更强，即**训练未见过的更难世界**；延迟 0 作为无延迟参照。每个单元 32 个新世界种子（170000 + 序号 + 单元序号 × 10000）。
- 指标：适应度 = 0.7×存活占比 + 0.3×终态队列能量占比；同时报告毒食物次数与存活率。

## 4. 假设（冻结）

分析单位是**训练种子**（8 个，按种子配对：同一训练种子在各条件下共享训练世界种子）。对每个训练种子 s，先在世界上取均值：D40(s) = 延迟 40 的两个单元里 laya − none 的平均适应度差；D0(s) = 延迟 0 的两个单元的同一差值。

- **H1（延迟世界里先验有用）**：mean_s D40(s) ≥ **+0.04**，且单侧符号翻转精确检验 p 达标（见 §5）。
- **H2（先验让结果更稳定）**：在 4 个单元的总体平均适应度上，跨训练种子的标准差 SD_none 与 SD_laya 满足 SD_laya ≤ **0.67 × SD_none**，且单侧精确置换检验 p 达标。
- **H3（先验的价值随延迟增加）**：mean_s (D40(s) − D0(s)) ≥ **+0.03**，且符号翻转精确检验 p 达标。

## 5. 统计方法（冻结）

- H1、H3：对 8 个种子的差值做单侧符号翻转精确检验（2^8 = 256 种符号，p = 符号翻转后均值 ≥ 观测均值的比例）。
- H2：在每个训练种子内随机交换 laya 与 none 的标签（2^8 = 256 种），统计量 SD_none − SD_laya，p = 统计量 ≥ 观测值的比例。
- 三个假设用 Holm（总 α = 0.05；按 p 从小到大比较 α/3、α/2、α）；某个假设不成立，其后的都不宣称成立。“成立”须同时满足 Holm 与该假设的效应量阈值。
- 次要（描述性）：laya − vader 的每种子差值；两种欺骗强度、两种延迟的单元分别的差值；毒食物次数、存活率；每个训练种子的原始数字。
- 不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。
