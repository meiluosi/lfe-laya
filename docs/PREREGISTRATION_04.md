# 预注册 04：先验在“后果延迟更长、欺骗更强”的世界里是否更有价值、更稳定

状态：**假设与协议在训练开始前冻结**（冻结提交见 §9；训练出的 24 个基因组的哈希在训练完成后、评估前追加冻结）。冻结后不得修改 §2–§6。

## 1. 来源与动机

预注册 03 显示：预注册 02 的大效应（laya 对 none +0.15）没有被 3 个训练种子稳定复现，但出现了两个**事后**观察：
(a) 有先验的个体结果更稳定（laya 三种子 0.49–0.51，none 0.35–0.48）；(b) 增益主要出现在后果延迟的世界（延迟 20 的单元仍领先约 +0.10），无延迟时种子 2、3 的无先验个体几乎追平。
本次用**全新的训练种子**（11–18）把这两个观察变成预先声明的假设。预注册 03 的结论不变，不据此调整本次的任何阈值之外的东西。

## 2. 被测系统（冻结）

3 个条件 × 8 个训练种子（11–18）= 24 次独立进化，设置与预注册 02/03 完全相同，只有训练种子不同：结构化个体 v2，40 代，种群 24，σ 0.25，学习率 0.1，K=32，危害封顶 4，训练世界延迟 20，每代 6 个训练世界（训练方言词池，含 25% 欺骗的混合）。

| --- | --- |
| laya | 固定 Laya 对描述的缓存判断 |
| none | 无先验 |
| vader | VADER 情感词表（独立来源） |

## 3. 评估世界（冻结）

- 留出方言词池与 Laya 先验表（同 02/03；该词池已被评估过两次，只看汇总，未用于调参，见 §7）。K=32，危害封顶 4，8 个个体，无繁殖。
- 4 个单元：延迟 {0, 40} × 欺骗 {0.25, 0.40}。延迟 40 比训练时（20）更长，欺骗 0.40 比训练时（最高 0.25）更强，即**训练未见过的更难世界**；延迟 0 作为无延迟参照。每个单元 32 个新世界种子（170000 + 序号 + 单元序号 × 10000）。
- 指标：适应度 = 0.7×存活占比 + 0.3×终态队列能量占比；同时报告毒食物次数与存活率。

## 4. 假设（冻结）

分析单位是**训练种子**（8 个，按种子配对：同一训练种子在各条件下共享训练世界种子）。对每个训练种子 s，先在世界上取均值：D40(s) = 延迟 40 的两个单元里 laya − none 的平均适应度差；D0(s) = 延迟 0 的两个单元的同一差值。

- **H1（延迟世界里先验有用）**：mean_s D40(s) ≥ **+0.04**，且单侧符号翻转精确检验 p 达标（见 §5）。
- **H2（先验让结果更稳定）**：在 4 个单元的总体平均适应度上，跨训练种子的标准差 SD_none 与 SD_laya 满足 SD_laya ≤ **0.67 × SD_none**，且单侧精确置换检验 p 达标。
- **H3（先验的价值随延迟增加）**：mean_s (D40(s) − D0(s)) ≥ **+0.03**，且符号翻转精确检验 p 达标。

## 5. 统计方法（冻结）

- H1、H3：对 8 个种子的差值做单侧符号翻转精确检验（2^8 = 256 种符号，p = 符号翻转后均值 ≥ 观测均值的比例）。
- H2：在每个训练种子内随机交换 laya 与 none 的标签（2^8 = 256 种），统计量 SD_none − SD_laya，p = 统计量 ≥ 观测值的比例。
- 三个假设用 Holm（总 α = 0.05；按 p 从小到大比较 α/3、α/2、α）；某个假设不成立，其后的都不宣称成立。“成立”须同时满足 Holm 与该假设的效应量阈值。
- 次要（描述性）：laya − vader 的每种子差值；两种欺骗强度、两种延迟的单元分别的差值；毒食物次数、存活率；每个训练种子的原始数字。
- 不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 10. 结果（2026-10-11，一次性运行；原始输出 `experiments/evo/heldout-long-eval-01/results.json`）

按冻结协议运行一次，24 个基因组哈希校验通过，未重跑。8 个训练种子（11–18），4 个单元 × 32 个世界。

| 假设 | 统计量（阈值） | 单侧精确 p（Holm α） | 种子逐个 | 正式结论 |
| --- | --- | --- | --- | --- |
| H1 延迟 40 世界里 laya 优于 none | 平均差 +0.032（≥ +0.04） | 0.0039（0.0167） | 8/8 为正：0.029, 0.031, 0.029, 0.030, 0.018, 0.064, 0.027, 0.030 | **不成立**：显著但效应量未达预设阈值 |
| H3 先验的价值随延迟增加（D40 − D0） | +0.143（≥ +0.03） | 0.0039（0.025） | 8/8 为正：0.129, 0.131, 0.081, 0.144, 0.145, 0.213, 0.146, 0.156 | **按协议的逐步规则不宣称成立**（见下） |
| H2 laya 跨种子标准差 ≤ 0.67 × none | SD 比 2.21（laya 0.0185，none 0.0084） | 0.926（0.05） | 8/8 种子里 laya − none 的总体均值为负 | **不成立，且方向相反** |

**关于 H3 的说明**：协议规定按 p 从小到大逐步检验，前一个不成立则后面都不宣称成立。H1 与 H3 的 p 并列（都是 1/256 = 0.0039），H1 排在前面且效应量未达标，所以 H3 按规则不宣称成立。H3 自身的条件（p < α 且效应 ≥ +0.03）实际上满足；这里并列排序是协议没有预见的细节，我们不改变正式结论，但如实披露：**H3 的数据支持是强的（8/8 种子同向、效应 +0.14）**。

各单元（8 个训练种子平均；适应度 / 存活率）：
- 延迟 0、欺骗 0.25：laya 0.527 / 0.691；none **0.612** / 0.674；vader 0.488 / 0.630
- 延迟 0、欺骗 0.40：laya 0.397 / 0.529；none **0.533** / 0.599；vader 0.410 / 0.545
- 延迟 40、欺骗 0.25：laya **0.367** / 0.506；none 0.272 / 0.352；vader 0.314 / 0.430
- 延迟 40、欺骗 0.40：laya 0.328 / 0.456；none **0.359** / 0.444；vader 0.312 / 0.430

laya − none 分单元的 8 种子平均差：延迟 0 欺骗 0.25 −0.085；延迟 0 欺骗 0.40 −0.136；延迟 40 欺骗 0.25 **+0.096**；延迟 40 欺骗 0.40 −0.031。总体平均适应度：laya 0.405，none 0.444，vader 0.381。

**如实结论**
1. **先验的价值高度依赖世界**。没有后果延迟时，无先验的个体显著**更好**（8 个种子都是 laya 更差，−0.09 到 −0.14）：个体靠自己尝试学得很快，先验反而带来误导（尤其欺骗 0.40）。只有在**后果延迟 40 且欺骗不强（0.25）**时，先验才有明显优势（+0.096，8/8 种子为正）。延迟 40 加上欺骗 0.40 时，优势消失（−0.031）。
2. 预注册 03 的两个事后观察中，“先验在延迟世界里更有价值”得到确认性支持（H3，8/8 种子），但“先验让结果更稳定”**被推翻**（H2：laya 的跨种子标准差反而是 none 的 2.2 倍）。预注册 03 中 laya 看起来更稳定，是因为只有 3 个种子。
3. laya 对 vader：延迟 40 的单元 laya 稳定更好（8/8 为正，+0.005 到 +0.050），延迟 0 的单元差异小且一个种子明显为负（−0.089）。描述性，不是确认性假设。
4. 训练与评估的差别：训练在延迟 20、欺骗至多 0.25 的混合世界；评估包含训练未见的延迟 0/40 和欺骗 0.40，所以本次检验的是泛化。无先验个体在延迟 0 的世界泛化得很好，先验个体没有。这也可能说明进化出的先验用法对训练分布过拟合。
5. 限制不变（§6）；此外，训练分布与评估分布的不一致使“先验有害”的结论只适用于该泛化设定，需要在对应世界里重新进化来确认。
