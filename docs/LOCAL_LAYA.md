# Laya 本地运行

日期：2026-09-29。本机已经运行真实 Laya MPS 推理，并驱动最小 TS 世界和独立小策略训练。完整 M0 状态与证据以 [完成审计](m0/ACCEPTANCE.md) 为准；本地可运行不等于持续学习有效。

## 实际环境

| 项目 | 已记录结果 |
| --- | --- |
| 机器 | Apple M4、16 GiB 统一内存、arm64、macOS 26.2 |
| 前端 | Node 24.7.0、npm 11.5.1 |
| Python | 项目内 uv 0.12.19、CPython 3.12.11；未修改系统 Python 3.14 |
| 模型运行时 | Laya 0.3.21、torch 2.14.0、transformers 5.17.0；实际设备 MPS，已完成测量中无 CPU 回退 |
| 默认 checkpoint | `convaiinnovations/laya`，revision `55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851` |
| 模型文件 | 英文清单 846,218,761 bytes；多语言对照 678,210,960 bytes；模型卡均为 Apache-2.0，清单含逐文件 SHA-256 |
| 本地占用 | 本轮 `.models` 约 1.5 GiB、`.venv` 约 794 MiB，随后续记录与运行副本增加；不是运行内存需求 |

完整依赖锁定在 `requirements-m0.lock`。独立环境绕过本机系统 Python 的 pyexpat 链接故障；没有安装 CUDA、Ollama、MLX 或 Docker。

英文与多语言 checkpoint 顺序比较。开发明确情境的结果分别为：多语言数值模板 0/12、自然语言模板 1/12；英文自然语言模板 12/12，因此在留出评估前选择英文版本。中文展示与英文模型输入分开；简单题正确不保证连续觅食成功。

## 运行方式与资源边界

按 [运行手册](m0/RUNBOOK.md) 安装、下载固定版本并运行。模型适配器加载一份固定 Laya，个体小策略、优化器与经历独立；本地 HTTP 服务仅绑定 `127.0.0.1:8765`，不会自动随前端启动。当前真实记录页读取已有日志，不需要常驻模型服务。

SDK 首次加载会规范化 tokenizer 配置。本项目保留原始文件，在隔离运行目录复制配置并硬链接权重；加载时校验原始清单，记录规范化后 tokenizer 哈希。不能为消除校验失败而关闭完整性检查。

批量 1/8/16/32/48 已各运行三次，中位整批耗时约 259/1381/2515/5212/6857 ms；当时本机有其他计算任务，不是空载性能。记录包含冷加载、各次原始耗时、RSS 和 MPS driver 指标，不能简单把统一内存各口径相加。联合推理与训练预算另行测量，不能据此承诺 48 个体实时学习。

Python 进程内拒绝网络连接、HTTP 健康/失败/重试以及联合预算分别由 `offline_probe.py`、`http_probe.py`、`joint_probe.py` 验证；实际是否完成以 [审计表](m0/ACCEPTANCE.md) 为准。离线测试不关闭用户系统网络。进程失败不会静默改为规则模式。

原始证据在 `experiments/m0/evidence/`，固定模型来源在 `experiments/m0/model-manifests/`。M1 的完整生态和 M5 的持续学习收益仍需单独验证。
