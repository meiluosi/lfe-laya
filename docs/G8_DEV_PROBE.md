# G8 S3：开发期探针（校准世界上的指标量级，非确认性）

日期：2026-10-28。目的：用 S1 选定的世界（S20 T26 I16，训练方言池）看 G8 各指标的量级，作为冻结预注册阈值的依据。基因组用开发期的 plain / regime（laya 先验，训练种子 201、202，**只有 2 个种子**），不是 G8 要评估的预注册 17 基因组。每个（种子，类型，模式）12 个世界；世界种子 800000 起，与校准用的世界种子重叠（同属训练划分，不是评估世界）。原始输出 `experiments/evo/g8-dev/{abab,long,half}`。

## 结果

**A/B/A/B/A（abab）纯种群，regime − plain（2 个种子）**

| 指标 | 种子 201 | 种子 202 |
| --- | --- | --- |
| 建立率（plain → regime） | .75 → .83（+0.08） | .67 → .83（+0.17） |
| 最后两阶段平均个体数 | 7.1 → 9.2（+2.1，约 +30%） | 8.4 → 9.1（+0.7，约 +8%） |
| 恢复比 | .33 → .47（+0.14） | .48 → .50（+0.02） |

方向一致为正，幅度小，2 个种子的间隔不能排除零。

**A/B/B/B/A（long，B 持续 3600 tick）**：plain 与 regime 在所有种子里建立率都是 **0**（平均个体数 0.3–0.4）；种群在长停留里几乎全部消失。这个模式在当前繁殖世界里**不可评估**——校准只在 abab 上做，长停留使世界过于严酷。

**A/B′/A（half，部分反转）**：建立率 +0.17 / −0.08，平均个体数 −1.1 / +0.6，恢复比 −0.06 / −0.03；没有一致方向。

**混合种群与中性对照（abab、half）**：每个世界最终基本由一个类型占满（占比几乎都是 0 或 1）；中性对照（两个标签同一基因组）的占比同样分布在 0 到 1 之间；plain 与 regime 的混合在 2 个种子里方向相反（种子 201 里 regime 占满较多，202 里 plain 占满较多）。**漂变的幅度与我们要检验的效应同量级甚至更大**，混合种群无法作为确认性比较。

## 对设计的修订（相对 `docs/DESIGN_G8_ECOLOGY.md` §3.6）

1. **H4（长停留）取消**：当前世界下不可评估（建立率 0）。若以后要检验，需要另行校准一个更宽松的长停留世界，不在 G8a 里；
2. **H6（混合种群占比）降为描述性**：中性对照的离散已经说明占比被漂变主导，不再作为确认性假设，仍报告混合与中性对照的占比；
3. 确认性假设只在纯种群并排上做，模式为 abab（主）与 half（不拖累）；
4. 每个（种子，类型，模式）的世界数从 12 提高到 **48**：建立率是 0/1 变量，12 个世界时每个种子的均值标准差约 0.13；48 个世界约 0.07，才有希望在 8 个种子上分辨约 +0.1 的差异。

## 阈值草案（冻结前由你确认；单位 = 训练种子，8 个；留出方言池 heldout；laya 先验）

- **H1**（abab）：regime 建立率 − plain 建立率 **≥ +0.08**（开发期 +0.08、+0.17）；
- **H2**（abab）：regime 最后两阶段平均个体数相对 plain 的比例差 **≥ +10%**（开发期约 +30%、+8%）；
- **H3**（abab）：regime 恢复比 − plain **≥ +0.05**（开发期 +0.14、+0.02）；
- **H4′**（half，不拖累）：regime 最后两阶段平均个体数 − plain **> −1.5**（非劣效；开发期 −1.1、+0.6）；
- 统计：符号翻转精确检验，Holm（4 个假设，α = 0.05，只基于 p 值）；成立 = Holm 拒绝且效应量条件满足。

**预期**：H1–H3 的开发期幅度小、只有 2 个种子，阈值又贴近观测，**可能不成立**；H4′ 的开发期差已接近边距。不成立就如实记录。

## 限制

2 个开发期种子；开发期基因组与评估用基因组不同；世界种子与校准重叠；建立率很吵；长停留与混合种群因此被排除，意味着 G8a 能回答的问题比设计时窄：只回答“在会繁殖的反转世界（abab、half）里，分账本的先天结构的种群是否更容易存续和恢复”。
