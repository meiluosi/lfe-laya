# 预注册 05：在“需要理解”的事实方言上，Laya 是否比情感词典更能判断食物

状态：**冻结时写明（见 §6）**。冻结后不得修改 §1–§4；在冻结提交推送前，不得用标签计算该方言池上的任何指标。

## 1. 问题与假设

预注册 02/03 显示：在情感倾向明显的描述里，独立的 VADER 词典驱动的个体与 Laya 驱动的个体相差无几（H3 不成立）。这可能因为那些描述主要靠“褒贬词”就能判断。本次构造一种**需要世界知识的事实方言**（`factual`，W5）：线索用中性语气陈述事实或间接知识（相近物种、产地、动物行为、加工后果、气味所暗示的化学物质），几乎没有褒贬词。问：**Laya 的判断是否比情感词典更能区分营养 / 有毒？**

- **H1（冻结）**：在 `factual` 池（4000 条）上，Laya 先验区分营养 / 有毒的 AUC 比 VADER 高至少 **0.10**，且配对自助法（按条目重采样，10000 次，随机种子 20261007）的 95% CI 下界 > 0。

不成立就如实报告：Laya 在这类描述上的优势没有超过情感词典，或者描述写得过于冷僻 / 过易。

## 2. 数据（冻结）

- 方言：`factual`（`packages/evo/ontology/dialects.json`；作者盲写：写作时没有看过任何 Laya 对该方言的输出，也没有对照词典调整；与其他方言没有完全相同的短语；词汇与其他方言共享约 20–26%，多为功能词）。池：`packages/evo/pools/factual.json`，4000 条，层级分布营养 / 轻毒 / 强毒 / 致命 ≈ 2040 / 901 / 766 / 293。
- Laya 先验表：`experiments/evo/laya-prior-v2/factual.jsonl`（只对文本计算，两种选项顺序平均，不使用标签）。
- 对照：VADER 词典（独立来源）、作者自写通用词典、打乱的 Laya。

## 3. 指标与分析（冻结）

AUC（营养 vs 有毒，P(吃) 作分数）；准确率（P(吃)>0.5）；“有信息线索”子集；分层级的正确率（营养 / 轻毒 / 强毒 / 致命）；次要比较：Laya − 通用词典、Laya − 打乱的 Laya（描述性）。分析脚本 `packages/evo/prior-quality-pool.ts`，正式运行校验池与先验表哈希（`experiments/prereg/hashes-05.json`）。只运行一次。

## 4. 限制（预先声明）

1. 方言是作者写的；这里的“需要理解”指需要事实与因果知识，不等于真实开放世界。
2. 池层面的先验质量，不涉及世界动力学；先验质量高不等于个体适应度更高（见 02、03）。
3. 本次不训练新个体，只评估先验。基于该方言的个体进化评估需另行预注册（W5b：层次信念）。

## 7. 结果（2026-10-06，一次性运行；原始输出 `experiments/evo/prior-quality-factual-01/results.json`）

按冻结协议运行一次，哈希校验通过。

| 先验来源 | AUC（全部） | 准确率 | AUC（有信息线索） |
| --- | --- | --- | --- |
| Laya | **0.775** | 0.706 | 0.811 |
| VADER 词典 | 0.583 | 0.560 | 0.590 |
| 作者自写通用词典 | 0.535 | 0.484 | 0.538 |
| 打乱的 Laya | 0.514 | 0.508 | 0.515 |

**H1 成立**：Laya − VADER = +0.192，95% CI [0.170, 0.212]（阈值 0.10）；Laya − 通用词典 +0.240，Laya − 打乱 +0.261。

分层级正确率（Laya / VADER / 通用词典）：营养 0.679 / 0.377 / 0.112；轻毒 0.728 / 0.747 / 0.872；强毒 0.728 / 0.752 / 0.880；致命 0.761 / 0.747 / 0.850。

**如实解读**
1. 在“需要世界知识”的描述上，情感词典几乎不比随机好（AUC 0.54–0.58），Laya 保持 0.775。这是对“Laya 读的是语义而不是褒贬词”的第一个确认性证据，也是预注册 02/03 中 H3 不成立的合理原因（情感倾向明显的描述词典也能读）。
2. 词典的 AUC 之外要看分层级正确率：词典对毒食物的“正确率”高（0.75–0.88），是因为它们几乎总说“别吃”（营养类的正确率仅 0.11–0.38）。这种偏向在致命世界里有风险价值，但会饿死——AUC 才是区分能力的恰当度量。Laya 在各层级相对均衡，但营养类的正确率（0.679）仍低于毒类，弱正向线索偏保守，与此前在测试方言上的观察一致。
3. Laya 的 0.775 低于其在情感方言上的 0.88–0.91：事实方言确实更难。
4. 仅为池层面的先验质量；先验质量更高是否转化成个体适应度，还未检验（需 W5b 的进化评估，见 §4.3）。
