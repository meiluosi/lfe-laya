## 工作 2 的开发期探针结果（2026-10-28，非确认性）：反转后伤害加大（`flipHarm`）的繁殖世界

模拟器新增默认关闭的 `flipHarm`（反转后原本有益的种类每口造成 flipHarm × 食量的伤害，受能量封顶；关闭时行为与旧版逐位一致，`tests/ctx.test.mjs` 有测试）。探针：开发期基因组（种子 201、202 的 plain 与 regime，训练在 flipHarm=1 的世界里），S20 T26 I16 繁殖世界，纯种群，abab 与 half，每个（种子，类型，模式）12 个世界，训练划分。原始输出 `experiments/evo/g10-lethal-dev/`。

| flipHarm | 模式 | 种子 | 建立率 plain → regime | 最后两阶段个体数 plain → regime |
| --- | --- | --- | --- | --- |
| 2 | abab | 201 | .75 → .58 | 5.4 → 4.9 |
| 2 | abab | 202 | .25 → .50 | 2.6 → 4.6 |
| 2 | half | 201 | .58 → .50 | 5.2 → 4.7 |
| 2 | half | 202 | .58 → .67 | 5.6 → 5.9 |
| 4 | abab | 201 | .17 → .17 | 1.5 → 1.0 |
| 4 | abab | 202 | .42 → 0 | 2.7 → 0 |
| 4 | half | 201 | .58 → .58 | 4.1 → 3.3 |
| 4 | half | 202 | .58 → .42 | 3.9 → 3.6 |

**读法**：没有一致方向。flipHarm=2 时两个种子方向相反；flipHarm=4 时两种类型的种群都大幅缩小（abab 里建立率降到 0.17 甚至 0），regime 不优于 plain。伤害加大只是让反转更致命，并没有让“保留”转化成种群优势；种群先被反转本身杀掉了。限制：2 个开发期种子、12 个世界；基因组没有在这个世界里训练过（可能训练错配）；校准参数（S20 T26 I16）是为 flipHarm=1 选的。**结论：这条路在当前设置下没有信号，不进入预注册 21**；若要继续，需要在该世界里重新训练个体并重新校准繁殖参数，属于更大的投入，等用户决定。
