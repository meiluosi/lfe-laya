# 世界复杂度设计：让“Laya 先验 + 个体经验 + 进化”有可测量的分工

状态：设计稿（2026-10-04）。尚未实现；每一项实现前先过 §9 的闸门。本稿回答：怎样系统性地提高世界复杂度，使三种机制——**Laya 先验（系统 1）**、**个体终身学习（后天）**、**进化（先天）**——的贡献能被分别测量，而不是为了“看起来难”而加难。

## 1. 为什么现在的世界不够

证据（`docs/EVOLUTION.md` 5.5–5.9）：

- 8 种食物、一生约 360 次决策时，**无先验、全试 + 自己的经验**的学习者已经接近预言机（K=8：0.722 对 0.764）；进化出的个体有无 Laya 先验差别不超过 ±0.02。
- 共享经验也几乎无增益——说明试错代价本来就小。
- 漂移（A/B/A）下个体与预言机差约 0.35，但预言机知道“何时反转”，个体拿不到，这个差距不能全算作学习不足。

结论：不是 Laya 没用，而是**这个世界里信息可以便宜地从经验中得到**。要让先验有可测的价值，世界必须让经验变贵、变慢、变危险，或根本给不出信息。

## 2. “足够复杂”的操作性定义：判别力，而不是难度

复杂度不是越难越好，而是**能把三种机制分开**。一个世界（或关卡）算“合格的基准”，当且仅当同时满足（均用同种子配对、95% CI、测试词汇与训练词汇不重叠）：

| 闸门 | 条件 | 含义 |
| --- | --- | --- |
| G1 信息有价值 | 预言机 − 盲规则 ≥ 0.35 | 世界里有值得知道的东西 |
| G2 经验不够 | 无先验终身学习者 ≤ 0.85 × 预言机 | 单靠试错补不齐，先验有空间 |
| G3 先验有用 | **最佳用法**（硬/自适应）的先验学习者 − 无先验学习者 ≥ +0.05，CI 下界 > 0 | Laya 先验确实带来增益（K 扫描表明“只排序”的软先验没有这个效果，故按最佳用法判定） |
| G4 增益来自语义 | 打乱先验（描述词与先验错配）≤ 无先验 + 0.01 | 排除“任何带噪信息都有用” |
| G5 增益来自 Laya 的广度 | Laya − 词典基线 ≥ +0.04（在保留的新“方言”上） | 排除“一个简单情感词典就够” |
| G6 仍有余量 | 目前最好的个体 ≤ 0.9 × 预言机 | 之后的改进还有可测空间 |

某个关卡不满足就调旋钮，而不是改判据。判据在跑最终实验前冻结（§9）。

## 3. 一个粗略的理论：什么时候先验值钱

设先验给出的判断准确率为 a，没有先验时个体要靠试错发现 K 种食物中每一种的好坏。

- **先验的价值** ≈ 试错总代价（种类数 K × 每种的错误率 × 单次伤害 × 重复被伤次数）− 先验错判带来的损失（错误率 (1−a) × 被错过的收益或被坑的伤害）。
- 试错代价随 **K、危害强度、不可逆性、每种遇到的稀疏度、反馈延迟与噪声**上升；先验的收益还随**线索可靠度 ρ** 上升。
- 当危害可致命（一口就死）时，试错不可行，先验（或进化出的先天厌恶）是唯一的保护——这时先验不是锦上添花，而是必要条件。

所以复杂度旋钮要同时作用在“经验变贵”和“线索仍可读”两侧。

## 4. 复杂度坐标轴（每一条都可独立开关，默认关闭）

每条轴给出：机制、需要的模拟器改动、对三种机制的预期影响、必须附带的对照。

### A. 词汇规模与稀疏度（无需改模拟器）

- 机制：每个世界的食物种类 K ∈ {8, 24, 64, 200}；出现频率服从 Zipf（指数 s ∈ {0, 1}），使多数种类一生只遇到 0–2 次。
- 预期：K↑、稀疏↑ ⇒ 逐个试错代价↑ ⇒ 先验价值↑（G3）。
- 对照：K 扫描（正在跑，§7）。
- 已有基础：`makeKinds` 的 `sensible/nonsense` 参数；Zipf 需要给 `spawnFood` 的种类抽样加分布（可选配置）。

### B. 危害强度与不可逆性（小改：`factor` 范围）

- 机制：有害食物的 `factor` 可到 −6；伤害按能量封顶，能量不够即死亡。一部分种类“一口致命”。
- 预期：个体无法靠试错学会致命种类 ⇒ **先验成为必要条件**；进化可能出现“先天厌恶”（Baldwin 式同化）；探索需要风险意识（能量充足才试）。
- 需要同时升级：学习信号 x 不能再被截断在 [−1,1]（否则分不清“有点毒”与“致命”）；用按期望尺度归一化的收益。
- 对照：致命比例 0 / 10% / 25%。

### C. 线索可靠度与欺骗（生成器改动，无需改模拟器）

- 机制：描述词由潜在属性（营养 n、毒性 τ、类别）经**随机文本生成器**产生：每个线索以概率 ρ 与属性一致，否则误导（“看起来有毒其实无害”的拟态、“闻起来很香却有毒”）。ρ ∈ {1, .9, .75, .6}。
- 预期：ρ 越低，先验越不可靠，终身学习越关键；最优策略是**软先验 + 经验修正**（这是前面已验证的结构）。
- 对照：已有“常识反转比例”，本轴把它推广为连续可调的 ρ 与多线索组合。

### D. 分级的与依赖状态的价值（小改）

- 机制：营养是连续量（0–1.5）；价值依赖饥饿程度（饱腹时吃补品不如保留空间）；“苦但补”的药性食物只在虚弱时有益。
- 预期：二分类先验（能不能吃）不够用，需要分级先验（Laya 的 `score` 题型）与上下文；个体学习需要估计数值而不是符号。

### E. 时间动力学：成熟周期与季节（较大改动）

- 机制：食物有生命周期（青涩 → 成熟 → 过熟 → 腐烂），**描述随阶段变化**，价值随阶段变化；整个世界有季节性（“白天变短、叶子变红”）并改变供给。
- 预期：用语言描述的时间过程是 Laya 擅长、进化难以硬编码的内容（“过熟”“发酵”）；季节线索给个体一个**察觉环境要变了**的语言信号，解决当前“预言机知道何时反转而个体不知道”的不公平。
- 与漂移的关系：把抽象的 A/B/A 反转替换成有语义线索的周期，漂移的可学性才有意义。
- 需要：每格食物的“年龄”状态、阶段描述表、季节描述（观测里的环境级线索）。

### F. 延迟后果与自身感受（较大改动）

- 机制：毒性/营养在 d ∈ {0, 20, 60} 个模拟步后才生效；个体观测里出现**自身感受的语言描述**（“胃里绞痛”“暖洋洋、有精神”）。
- 预期：信用分配变难——个体必须把感受和**之前**吃的东西联系起来；感受是语言，Laya 能解读它的好坏含义，成为先验的新入口。
- 需要：个体的待生效伤害队列；观测里的自我感受字段；学习器带资格迹（`learner.ts` 已有）。

### G. 地形与威胁的语义（大改）

- 机制：非食物的语义对象：荆棘丛（移动代价）、薄冰（伤害）、洞穴（休息恢复）、“巨大的影子”（捕食者靠近）。描述是自然语言，效果隐藏。
- 预期：把语义通道从“能不能吃”扩展到“能不能去”“要不要躲”，Laya 的常识覆盖面成为核心。
- 放在最后：改动大，且需要新的行为（躲避、避险）。

### H. 社会观察（中改）

- 机制：观测里加入邻居**可见状态的语言描述**（“脸色发青、浑身发抖”“精力充沛”）；不共享参数、不共享内部经验，只是看见。
- 预期：个体可以从他人的后果学（观察学习）——比逐个亲身试错便宜，也比共享经验更符合隔离原则。Laya 解读“发抖”的含义。
- 对照：邻居描述打乱 / 关闭。

### I. 生态与多代（已有基础）

- 机制：打开繁殖与变异，长视野，多代；基因（好奇心、信任、校准、风险）由自然选择而不是外层 ES 选择。
- 预期：检验“先天吸收后天”（B 的致命种类 + 多代 ⇒ 先天厌恶）是否出现。

## 5. 复杂度阶梯（累积式预设，同时支持任意组合采样）

| 关卡 | 旋钮 | 需要的改动 | 假设（可证伪） |
| --- | --- | --- | --- |
| L0 | 现状（K=8，ρ≈常识，无危害放大） | 无 | 先验无可测贡献（已证实） |
| L1 | A：K=24 / 64，Zipf s=1 | 种类抽样分布 | **已部分证实**：线索可靠时，硬先验 − 无先验随 K 上升（K=48：+0.088 [0.043, 0.134]）；软先验（只排序）无用 |
| L2 | + C：ρ=.75 的生成器与拟态 | 描述生成器（TS）、先验表重算 | **已部分证实**：硬先验在 25% 反转下显著输给无先验（−0.13 到 −0.18）；最优策略需要**自适应信任**（见 §8） |
| L3 | + B：致命种类 10–25% | `factor` 范围、学习信号归一化、风险意识 | 无先验学习者因试错致死而远低于有先验者（G2、G3 同时成立） |
| L4 | + F：延迟 20–60 步 + 自身感受 | 待生效队列、感受字段、编码白名单 | 单靠逐种类均值学习失效，需要资格迹与感受解读 |
| L5 | + E：成熟周期与季节线索 | 阶段状态与描述、环境级线索 | 季节线索让“遗忘/重试”从无用变有用；遗忘率被选择 |
| L6 | + G、H：地形/威胁/社会观察 | 地形语义、邻居描述 | 先验的覆盖面成为主导；观察学习显著降低试错代价 |

L1–L3 几乎不需要改模拟器核心，应先做；L4 起才触及核心，需要同时更新黄金测试隔离、契约夹具和 Python 编码白名单。

## 6. 描述词生成器：避免“为 Laya 量身定做”

这是最大的科学风险：如果世界的描述是我们按 Laya 擅长的方式写的，结论就不可信。措施：

1. **生成式本体**：每种食物先有隐藏属性（营养 n、毒性 τ、类别、成熟度），描述由随机文本生成器从属性产生；生成器代码、词表、模板独立于 Laya 的任何输出，**不根据 Laya 的反应调整**。
2. **多“方言”**：训练方言与测试方言在词汇、句式、修辞（比喻、否定、复合线索）上不相交；测试方言由一个**独立来源**写成（例如另行撰写的一批带比喻、转折、否定的描述），而不是同一模板换词。
3. **混合与冲突线索**：“闻着香但表面长斑”“其貌不扬却营养丰富”。
4. **词典基线（G5）**：用训练方言构建的情感词典分类器；若 Laya 在测试方言上不比它强，说明世界还不需要语言模型。
5. **打乱先验（G4）**与**加噪先验**：证明收益来自语义，并给出对先验错误率的敏感度曲线。
6. 先验计算的成本：每个独立描述约 0.1 秒（双顺序）；一个 2 万条描述池约一个多小时，一次性缓存，进化沙盒读缓存（已验证可行）。

## 7. 第一块证据：种类数 K 扫描（已在做）

`packages/evo/ksweep.ts` → `experiments/evo/ksweep-01`：K ∈ {8, 16, 32, 48}，常识正常 / 25% 反转；比较无先验（全试 + 经验）、软先验（全试，优先吃 Laya 看好的）、硬先验（Laya 否决）、盲规则、预言机。K=8 的结果：无先验 0.722，软先验 0.719，硬先验 0.680（−0.042，显著更差），预言机 0.764。结果见 §11（先验价值随 K 上升，线索不可靠时硬先验有害）。

## 8. 学习器与进化的配套升级（否则复杂世界只会测出“方法太弱”）

世界变复杂后，现有的“按描述词记平均后果”会先失效，需要同步升级：

| 部件 | 现状 | 升级 |
| --- | --- | --- |
| 先验 | 缓存的 Laya P(吃)（二分类） | 分级（`score` 题型）、多提示集成（降低 7% 错判）、用提示间分歧估计不确定度 |
| 信任 | 固定基因 n0（信任强度） | **自适应信任**（K 扫描的核心结论）：个体估计先验的可靠度 r̂（先验与自己的经验一致的比例，带先验强度的贝叶斯更新），可靠则让先验阻止试错，不可靠则退回全试；基因只决定初始信任与更新速度 |
| 信念 | 每种描述词一个均值（`structured.ts`） | 层次贝叶斯：用 Laya 向量嵌入（PCA 到 16–64 维）做在线线性回归，使“吃过 A”的经验推广到语义相近的 B；保留逐种类项 |
| 信用分配 | 即时收益 | 带资格迹的 TD，把延迟感受与此前的进食关联 |
| 探索 | 好奇心常数 | 风险意识：能量缓冲够才试；Thompson 采样 |
| 变化检测 | 固定遗忘率 + 重试 | 对残差做变点检测（CUSUM），自动触发遗忘 |
| 基因 | 信任、好奇心、阈值、遗忘、重试 | 加：对 Laya 先验的**校准**（斜率与偏置）、嵌入轴上的先天偏置向量（进化微调系统 1 接口）、风险偏好、学习率 |
| 进化 | 外层 ES，每代 6 个世界 | 更大种群、课程（L1→L6）、方言保留评估；并行做一组“打开繁殖的自然选择”对照 |

## 9. 评估协议与预注册

1. 每个关卡先过 G1–G6（自动脚本 `ladder.ts`，同种子配对，CI）；不通过则调旋钮，记录调了什么。
2. 调参只用**训练方言与训练种子**；测试方言与评估种子在最终运行前冻结，写进预注册文件（沿用 `docs/ECOLOGY_EXPERIMENT.md` 的做法）。
3. 报告必含：适应度、毒食物次数、致死数、**每种食物的学习曲线**（首次遇到后多少次才稳定）、信念校准（Brier）、先验贡献（相对打乱先验）、遗忘/重试基因的取值。
4. 失败与负面结果保留（已有 5.5、5.9 的先例）。
5. 先验、学习、进化三者的因果归因：2×2×2 消融（先验有/无 × 学习有/无 × 先天进化有/无），并附打乱先验、词典、预言机。

| 25% 反转 | 32 | 0.332 | 0.720 | 0.705 (-0.014 [-0.045, +0.019]) | 0.545 (-0.175 [-0.240, -0.106]) | 0.773 | 577 / 583 / 199 |
| 25% 反转 | 48 | 0.332 | 0.632 | 0.624 (-0.008 [-0.048, +0.029]) | 0.469 (-0.163 [-0.234, -0.098]) | 0.736 | 789 / 763 / 291 |

读法：
1. **先验的价值随种类数上升（线索可靠时）**：硬先验相对无先验的差从 K=8 的 −0.042（反而更差）升到 K=48 的 **+0.088 [0.043, 0.134]**，毒食物从 799 次降到 158 次。这正是 §3 的预测：试错代价随 K 上升，先验才有东西可省。
2. **线索被反转 25% 时，硬先验在所有 K 下都显著更差**（−0.13 到 −0.18）。先验可靠与否，决定它是帮手还是陷阱。
3. **“软先验”（只给追逐目标排序）在所有 K 下都≈无先验**，毒食物也没减少（799 → 740）。排序不阻止试错，所以不省代价。**先验只有在“减少了需要试的东西”时才有价值**。
4. 因此需要的不是固定的硬/软两选一，而是 **个体一生内估计先验自身的可靠度**（先验判断被自己的经验推翻的比例），可靠就当过滤器用，不可靠就退回全试；初始信任是基因、之后的调整是后天。见 §8。
5. K=8 时无先验学习者 0.722，离预言机 0.764 只差 0.04——解释了为什么此前的所有实验都看不到先验的贡献。

## 12. 与既有边界的关系

- 隐藏真值与预言机只用于度量上限（`AGENTS.md`）；描述生成器的潜在属性同理，不进入任何个体输入。
- Laya 保持固定；先验是它对描述文本的真实输出，缓存不等于代理模型。若描述池无法覆盖开放世界，必须在运行时调用 Laya 并缓存，且记录输入输出与版本。
- 先天参数（基因）与后天信念（个体经验）分开标注；社会观察是**看见他人的状态**，不是共享内部经验。
- 计算预算：不设上限，但先验池、课程进化和三因素消融需要连续数小时的机器时间；实验只在机器醒着时推进。

### 14.1 阶段结论（2026-10-05 下午）

### 14.6 预注册 04 的含义（2026-10-11）

先验只在“试错代价被后果延迟放大”的世界里才有净收益；在即时反馈的世界里，个体自学足够快，先验（尤其被欺骗时）反而拖累。这正是 WORLD_COMPLEXITY 第 3 节“什么时候先验值钱”的预测，现在得到了确认性证据的支持：先验值钱的条件是 经验昂贵（延迟、致命）且线索基本可靠（欺骗不强）。下一步：W5b 层次信念能否在欺骗强的世界里挽回先验的价值；在延迟 0 / 40 的对应世界里分别进化，检验“先验有害”是否来自训练分布不一致。

### 14.7 预注册 06 的含义（2026-10-13）

“先验值钱的条件是经验昂贵（延迟、致命）且线索基本可靠”现在有了两个独立的确认性证据（预注册 04、06）。更干净地说：匹配训练后，先验在即时反馈的世界里中性、在延迟 40 的世界里 +0.05（6/6）；强欺骗削弱收益。W5b 的层次信念（共享 Laya 嵌入）没有带来额外收益，不作为主要贡献。剩余未回答的问题：词典 / 其他先验来源在匹配训练下的比较（vader 条件未纳入）；更长延迟（如 80+）；事实方言上 H2 型收益未达阈值（+0.024），说明先验质量更低时收益更小。

### 14.8 预注册 07 的含义（2026-10-14）

至此，W3–W9 的核心问题有了确认性回答：(1) 先验在后果延迟时稳定有益，且随延迟增加（40 → 80：+0.04 → +0.07）；(2) 即时反馈的世界里中性；(3) 在需要世界知识的描述上，Laya 比情感词典更好（+0.05），词典先验甚至比无先验更差；(4) 强欺骗削弱收益；(5) 层次信念（Laya 嵌入共享）无增益。尚未做的：W7（成熟周期与季节）、W8（地形、威胁与社会观察）；更多种类和更长延迟；用需要世界知识的方言做训练（本次仍在情感方言上训练）。

### 14.9 预注册 08 的含义（2026-10-15）

“用需要世界知识的方言训练能放大 Laya 与词典的差距”没有得到支持；但发现 Laya 的价值之一是**先验可靠性跨方言稳定，使进化出的信任程度可迁移**，词典则不能。后续可检验：多方言混合训练、训练与评估方言交叉。W7（成熟周期）与 W8b（社会观察）的开发期预实验已在分支 `w78` 进行（见 docs/W7_W8_DESIGN.md）。
