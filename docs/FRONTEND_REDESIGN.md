# 前端重设计：观察台（Studio）

状态：进行中。起始 2026-10-02。用户授权彻底重做前端展示与交互；算法不动。现有 `/lab.html` 与 P0 页在新界面通过验收前保留，不删除。

## 目标

把“带控制面板的模拟器”改成“一卷可读的录像带加一台显微镜”：时间是主轴，对象是入口，学习过程可见，证据边界清楚。入口 `/studio.html`。

## 设计原则

1. **一切是带子的投影。** 任一时刻的画面 = 带子在时刻 t 的状态。实时只是播放头在末尾；回看、对照、分支都是拖动播放头和“从这里分叉”。不为展示另造数据。
2. **世界先行，信息跟着选中对象。** 画布铺满；没有常驻侧栏。选中个体后，“现在 / 为什么 / 学到了什么”在画布内展开，技术细节进证据抽屉。
3. **语义缩放。** 远看生态（密度、营养热度、谱系），中看个体与轨迹，近看感知圈、候选动作、记忆点与概率。
4. **学习可见但不夸大。** 同一观测的前后策略概率并排表示，固定标注“概率变化不等于生存更好”。不因策略版本上升而给生命加特效。
5. **叙事只来自真实事件。** 事件文字由模拟事件生成；不编造意图、性格或理由。
6. **证据边界不可隐藏。** 模式徽标（真实·规则 / 固定 Laya / 学习中 / 冻结 / 回放 / 降级）固定在可见位置，带文字，不只靠颜色。
7. **画面不驱动行为。** 视图层只读；干预只能经 Worker 命令在动作边界生效。减少动效开关保留。
8. **颜色不是唯一通道。** 体型用轮廓与运动节律区分，颜色留给能量与谱系，并配形状或文字。

## 使用场景假设（可随时调整）

日常观察与分析为主，兼顾向他人演示：默认画面简洁，证据抽屉提供高信息密度。先桌面与笔记本，窄屏退化为底部抽屉，不作为首轮验收重点。

## 技术约束与方案

- 保留 React + PixiJS + 现有 Worker/Session/协议；视图层放在 `src/studio/`，与 `src/lab/` 并存。
- 带子：`Replay` 增加关键帧、任意时刻跳转（`seek`）和轻量索引；跳转后仍逐条校验哈希，不跳过验证。
- 实时回看：暂停 → 导出当前记录 → 在回放中跳转；“回到现在”退出回放，原会话保持不变（不重训、不改世界）。
- 营养热度图用 PixiJS 滤镜/网格着色，不引入新依赖。
