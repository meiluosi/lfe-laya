# M0 首个算法验证切片

状态：2026-09-29，A–F 已完成，见 [实验结果](RESULTS.md) 与 [完成审计](ACCEPTANCE.md)。下文保留任务规格；不将 P0 动效作为算法能力证据。

## 要回答的问题

先验证：真实 Laya 的候选偏好能否参与一个局部决策，并使模拟器产生可核对的执行结果？再验证：同一个体是否能利用这些真实后果更新独立的小策略？最后通过对照判断更新是否有用、Laya 是否有额外贡献。

三者分别报告，不合并成一个“AI 已跑通”结论。路线仍为 B：固定 Laya + 个体轻量学习网络。完整生态中的持续学习效果留给 M5 验证。

## 最小任务边界

- 使用无界面的简化资源采集任务，提供有限局部感知、有限地点记忆、移动/摄食/休眠候选、能量与终止反馈。动作由环境校验并执行。
- 单个体跑通后，用两个独立实例验证参数、优化器、经验、记忆和随机状态隔离；这一步不引入多体竞争。
- 关闭繁殖、变异、交流和经验传承；柔团、尾游、节虫先采用相同身体条件，仅作为三种外观。后续身体差异独立消融，不与算法比较一起改变。
- 一个短动作循环足以验证集成；它不能证明长期适应。只有完成预定训练与评估，才能讨论行为收益。
- 此任务实现遵循现有 TS 世界归属方案，不复制 P0 的追食脚本，也不额外维护一份 Python 生态规则。最小环境的代码是否扩展为 M1，取决于契约与验证结果。

## 按顺序交付

| 任务 | 输入与依赖 | 具体产物 | 完成条件 |
| --- | --- | --- | --- |
| M0-A 输入与执行契约 | 架构中的局部观测、有限候选和身份字段 | 版本化请求/提案/执行结果；无模型测试 | 只暴露许可输入；非法、过期与重复提案不改变世界；候选顺序改变不改变语义映射 |
| M0-B 一次真实决策 | A；本地环境与单个固定 checkpoint | 运行清单、实际输入输出、实际设备与耗时、一次成功或拒绝的执行记录 | 模型响应经过验证后交给执行器；执行结果能追溯；原始输出缺少全候选偏好时明确记录，不伪造分布 |
| M0-C 最小经历闭环 | A/B；简化资源任务 | 连续真实动作与反馈；独立规则基线；能量账本 | 观测→提案→执行→反馈可逐条核对；模型与模拟器测试分开；失败/超时不产生虚构奖励 |
| M0-D 独立小策略更新 | C；预先固定算法、奖励、更新预算 | 单个体参数变化、版本及经验引用；双实例隔离与恢复记录 | 真实执行反馈驱动更新；冻结不更新参数；更新甲不改变乙；恢复后可继续同一学习过程 |
| M0-E 预定对照 | D；训练/评估配置已冻结 | 全部种子结果、适应/遗忘/成本报告，包括失败样本 | 不只展示最好的一次；区分记忆、参数学习和 Laya 贡献；未达到收益标准时如实报告 |
| M0-F 展示接入判断 | C 起可预览，D/E 完整后判断学习展示 | 可被渲染器读取的只读快照与真实事件；仍未接入部分的清单 | 同一记录换三种外观不改变动作、奖励或评估结果；前端显示的变化都有记录来源 |

A 可在无模型、无网络环境验证。B 以当时核实的官方 SDK、许可和 checkpoint 为准，不使用猜测的接口。B 不能用合成结果代替；合成样本只进入单独标记的契约测试。C/D 的开销测量决定 E 的规模，不先承诺 48 个体实时学习。

## 评估开始前必须固定的配置

以下各项已写入 [版本化配置](../../experiments/m0/config/learning.json)，配置摘要记录在 `experiments/m0/config/frozen-sha256.json`，正式运行另存源码 SHA-256。冻结后输入校验的修正单独记载，不能悄悄改变实验参数或判据。

1. 世界规则：空间大小、可达性、局部感知、记忆容量、能量初值/上限、资源补给、动作持续步数、消耗、终止与截断规则。
2. 模型和策略：checkpoint/revision、输入模板、候选编码、偏好融合、网络结构、优化器、学习率、折扣、探索、更新频率和样本预算。
3. 奖励：来自实际摄食、能量消耗及终止后果的明确公式；不奖励指定方向、角色外观或“画面有趣”。避免能量变化与其分项重复计奖。
4. 随机性与数据划分：训练种子、开发集与留出环境、每组预算、独立随机流。留出评估前冻结配置和判定标准；之后的改动归入新实验版本。
5. 比较条件：观测、候选、身体参数、环境日程与模拟时长一致；模型推理和训练真实耗时单独计量。

学习规格沿用 [持续学习方案](../LEARNING.md)。M0 先做集成与更新的工程验证；行为实验再引入隐藏的 A→B→A 资源日程。阶段 ID、未来资源分布及评估真值不进入个体输入，也不通过候选说明间接泄露。

## 证据与结论分层

| 要区分的作用 | 必要比较 | 可以回答什么 |
| --- | --- | --- |
| 参数学习 | B 持续更新 / B 冻结，记忆规则一致 | 参数更新是否带来额外收益 |
| Laya 先验 | B / 无 Laya 的小网络；预算及非消融条件一致 | Laya 是否帮助适应，还是增加成本或带来负迁移 |
| 记忆 | 固定 Laya 仅当前观测 / 固定 Laya + 同规格记忆 | 行为变化是否仅由记忆解释 |
| 环境基本可解性 | 规则基线与各组 | 环境或执行错误是否掩盖模型表现；不保证规则一定最优 |

保留净能量收益/采食、存活与死亡、阶段切换后的适应、返回 A 时的保留或恢复，以及每次推理/更新的开销。恢复指标及收益阈值在开发阶段定义并冻结；不能按留出结果挑指标。终止、请求失败和未完成阶段全部纳入结果，不能删掉失败个体或无限重跑挑成功样本。

最小证据包：运行清单与配置、真实决策记录、执行事件与奖励分项、参数更新与检查点引用、全部评估结果及限制说明。只记录实际输入输出，不补写模型的心理活动。严格回放按已记录动作执行，不重新调用模型或训练。

## 展示上的落实

默认呈现生命、食物、运动和干预结果；选中后查看经历；主动打开实验视图才看到偏好分布、参数版本与对照条件。运行模式、示例/真实、等待/失败/降级等影响理解的标识始终可见。

运动方向取自模拟器，摆尾与伸缩跟随已执行动作，摄食反馈跟随真实摄食事件。没有改善时不添加“升级”外形或成功故事。装饰性插值不改变世界状态；切换皮肤或关闭渲染不能改变算法结果。
