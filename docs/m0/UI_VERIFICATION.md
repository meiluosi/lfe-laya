## 数据归属

`export_view.py` 从实际 transition 中提取坐标、资源、能量、事件和奖励。页面加载后冻结数据对象；绘制、外形、播放进度属于展示状态。皮肤按钮仅重绘 canvas，不向模拟器或训练器提交指令。离线动作回放另由 `audit_records.py` 与同一 TS 核心逐步比较，不能以 UI 截图替代。

本页暂不提供现场干预、镜头缩放或实时模型运行。P0 的选择、跟随、镜头与示例干预仍在原型页中，标识保持分开；完整生态交互属于后续阶段。
