## 保留的调试事实

- 系统 Python 3.14 pip 存在 pyexpat 链接故障；使用项目内独立 CPython 3.12.11，未修改系统安装。
- Laya SDK 会规范化 tokenizer 配置；现保留原始 checkpoint 并通过隔离副本加载，原始 SHA-256 不变。
- checkpoint 的 `choice:11+` 温度被 SDK 限制；本任务至多六候选，仍不把偏好概率解释成生存成功率。
- HTTP 首轮探针受系统代理影响，已对本机 loopback 请求显式不使用代理并重跑通过，不修改系统设置；失败日志保留。
- 画图额外依赖单独锁定在 requirements-m0-analysis.lock，所有算法运行依赖版本保持不变。
- 原型构建有图表分块大于 500 kB 的提示；Python 测试有 Starlette/httpx 弃用提示，均非失败。当前 runner 不含整个长实验自动断点续跑 CLI。
