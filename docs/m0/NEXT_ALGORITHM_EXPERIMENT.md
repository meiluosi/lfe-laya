# M0 之后的算法问题与下一轮建议

状态：已结合 M0 完整在线与留出结果复核的后续实验草案，尚未执行，不改变本轮冻结配置或判据。B 在三组留出上达到探索性门槛，但任务辨别力、采样 RNG 和样本量限制仍支持下列优先级；详见 [结果](RESULTS.md)。

核心仍是：世界提出值得学习的问题，生命通过经历改变行为，展示帮助人看清这个过程。三种外形继续保留，不能通过预写性格、追食动画或外观升级代替算法进展。

## 先确保环境值得学习

M0 的 7×7 世界初始食物 120，每 4 步补充 5；单体每步最多移动并消耗 0.30，食物不会自然消退。全局供给多于单体消耗，旧食物会积累。A→B→A 改变新食物的位置分布，旧食物不被撤走；这足以测试接口与记录，却未必要求学习迁移。在线实验中初始冻结的小网络也在三组种子均存活到时限，支持继续检查任务难度，而非仅延长训练。

下一轮先用规则与随机合法策略建立难度基线：检查缺粮比例、探索距离、能量消耗和死亡时间，再固定资源预算。若引入食物腐败或移除，明确记入能量账本；不在展示端偷偷制造饥饿。难度调节使用开发种子，不把“所有个体必须存活”设为目标，也不为制造戏剧效果强制失败。

## 分别检查模型与融合方式

固定 Laya 在简单题表现好，但本轮连续运行中出现往返并死亡。先从实际轨迹抽取失败观测：有近处食物、多食物、墙边、旧记忆与空视野，检查候选顺序敏感性和行动重复。现有明确情境只覆盖当前位置摄食及东/南/西单目标，缺少北向明确题和多障碍路径，12 个留出样例也与开发模板非常接近；不能把 12/12 当作广泛理解。

本轮 B 把 Laya 的六项偏好作为小网络输入。初始化时它未必会遵循这些偏好，学习后也可能忽略它们。这是已经实现并可评估的一种融合，不代表 Laya 一定提供了有效先验。

如需比较其他融合方式，另开实验版本，保持世界、样本预算和策略参数量可比：先比较“偏好作为特征”与“有界的残差动作偏好”，同时保留无 Laya 和固定 Laya。额外结构必须说明输出、梯度和个体状态归属；不把更高置信度直接解释为更好生存率，也不静默改用规则动作来美化结果。

## 让效果指标能区分好坏

本轮奖励为能量变化除以 10，死亡额外扣 1。完整轨迹的未折扣奖励会相消为 `(最终能量−初始能量)/10−死亡惩罚`，对存活到末尾且接近能量上限的策略区分较弱。因此同时保留了采食、存活、阶段窗口和动作记录；不能仅凭末尾能量判断长期觅食能力。

后续在开发阶段明确主要指标及恢复阈值，再冻结配置。可研究环境切换后的缺能时间、获得单位可用能量的移动成本、恢复到预定生存水平所需的交互数；它们是待验证指标，不是已经证明有效的奖励设计。不能把相关分项与能量变化重复计奖。

留出比较另设明确的评估 RNG 日程，让学习后策略和初始化冻结策略从匹配的探索随机状态评估；当前 M0 的世界种子配对，但各自采样 RNG 延续不同经历。这一限制必须保留。当前留出仅改变资源随机种子，阶段时长与身体条件保持相同；没有验证未知变化时刻的迁移能力。新增调参后采用新的留出环境，不能重复使用已经查看的留出集挑最好版本。
