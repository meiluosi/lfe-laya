# 产品与模拟设计

状态：核心方向与学习主路线已确认，M0 技术预研已完成；完整生态的实施细节仍属后续设计。初始规模与决策预算按 [M0 结果](m0/RESULTS.md) 更新为 8 个体、每模拟秒一次决策，其余默认数值仍为调参建议。

## 1. 产品目标

用户扮演观察者与环境干预者，在一个持续运行的生态缸中追踪生命体、改变生存条件、比较不同世界的发展。

核心方向是“世界提供值得学习的问题，生命通过经历改变行为，前端把这个过程展示出来”。用户既能看见世界和谱系变化，也能追踪同一个体如何从经历中改变策略。学习机制详见 [持续学习方案](LEARNING.md)。

用户于 2026-09-29 明确：算法是核心，最终行为与学习效果取决于模拟、决策和学习机制；展示端不必强调算法术语。默认界面先呈现生命与环境，经历和实验细节按需展开。简洁展示不隐藏当前模式、示例来源、失败或降级。视觉表现服务于真实行为的可理解性，不能由预写剧情替代算法产生的后果。

本项目从生命游戏获得局部互动与涌现的灵感，首版采用带环境场的多智能体模拟，不保持康威生命游戏的原始规则，也不严格定义为经典元胞自动机。

## 2. 用户体验循环

1. 选择世界种子和大脑模式，启动一个培养皿。
2. 观察营养分布、个体活动与种群变化。
3. 跟随某个个体，查看局部感知、地点记忆、Laya 建议与最终行动，以及经历前后的策略差异。
4. 投放营养、绘制或移除障碍，观察行为是否改变。
5. 看到后代继承性状、谱系延续或灭绝。
6. 保存包含学习状态的快照，比较相同起点下允许学习、冻结策略或不同环境干预的结果。

## 3. 世界机制

### 空间与时间

- 连续二维位置，环境按栅格保存营养、通行性等属性。
- 首版采用封闭边界，生命体不能穿越墙体；不采用左右穿越的环面世界。
- 世界以固定模拟时间步更新，显示帧率独立。
- 同一模拟步使用冻结状态收集动作，再按明确顺序解决冲突。

### 资源循环

- 营养场可扩散，并按可配置速率获得外部补给；外部补给明确记账。
- 个体摄食将环境营养转化为体内能量，转化损耗记入账本。
- 基础代谢、运动和表达出的性状产生消耗，能量不足导致死亡。
- 死亡后部分储能返回环境，其余作为损耗；尸体不额外创造资源。
- 用户投放营养属于外部输入事件。
- 首版按能量账本验证收支闭合，不声称模拟真实热力学或完整物质守恒。

### 个体状态

每个生命体保存稳定 ID、父代 ID、出生步、位置、朝向、能量、年龄、性状、有限地点记忆、当前动作、最近决策引用及独立学习状态引用。学习状态包含小策略参数与版本、优化器、受控随机数和有界经验记录，由学习运行时管理。

首版性状建议包含：体型、移动速度、感知半径、代谢特征、风险倾向与繁殖倾向。速度与感知有明确能耗代价，体型影响容量和维持成本，避免每项参数越大越好。

模型相关行为倾向是否真的影响选择，由专项情境测试验证。改变提示描述不能直接作为“性状有效”的证据。

### 局部感知与记忆

- 只能看到感知范围内且未被障碍遮挡的食物与个体；具体遮挡实现可在 M1 中采用简单射线检测。
- 输入采用相对方向、距离与有限量的环境摘要，限制候选对象数量。
- 不提供全局资源地图、其他个体基因、能量或不可观察的计划。
- 首版记忆是固定容量的近期地点记录，例如“此处曾有食物”“曾受阻”；由实际事件写入，随模拟时间衰减。
- 后代默认不继承父代经历或训练后的策略；保存地点记忆不自动证明个体学会利用它。

### 动作与执行

首版动作为觅食、朝可见或记忆目标移动、探索、休眠和繁殖。每次决策从引擎生成的有限合法候选中选择一个。

规则、固定 Laya 与学习策略使用相同的观测、候选动作与动作持续时间。首版不将真实推理或训练毫秒折算为个体能量消耗，以免硬件差异改变生存结果；计算成本作为独立指标记录。以后加入“思考成本”时，以显式模拟规则定义，并单独进行对照。

运动、碰撞和短距离转向由引擎持续执行。主路线由固定 Laya 提供动作偏好，个体小策略结合自身经历选择行为或目标，不逐帧输出坐标。模型无法选择感知之外且从未记住的目标。

选择繁殖仅是提案，执行时仍需满足能量、空间和冷却要求。目标消失或条件变化时返回明确的执行失败原因，并在下个决策点重新感知。

繁殖为一次性动作，一个决策最多执行一次；移动、觅食和休眠可持续多个模拟步。动作失效后待机至下个决策点，不凭空替换成另一种模型选择。

### 繁殖与演化

- 首版采用单亲无性繁殖，减少初始机制数量。
- 后代从亲代获得能量，繁殖同时消耗额外成本；不能凭空生成有能量的后代。
- 性状在预设范围内小幅变异，变异使用受控随机数源。
- 选择压力来自生存和繁殖结果，不直接奖励“看起来有趣”。
- Laya 权重在一轮主路线实验内固定，个体小策略可在一生中持续更新；冻结评估时暂停参数更新。
- 后代继承性状并变异，但从统一初始化规则创建全新的小策略、优化器和空记忆。传递已学会的参数或经历属于后续单独实验，不能默认开启。
- 首版追踪谱系和性状分布，不把简单聚类称为生物学物种形成。
- 人口保护上限触发时阻止新增后代并记录事件；指标标注该限制，避免将其误认成自然承载力。

## 4. 大脑模式

| 模式 | 用途 | 用户看到的标识 |
| --- | --- | --- |
| 规则 | 可解释的基线和离线可玩模式 | 规则大脑 |
| 固定 Laya | 使用实际模型直接选择有限动作，参数不更新 | 固定 Laya，附模型版本 |
| Laya + 个体学习 | 主路线：固定 Laya 提供偏好，每个个体的小策略持续学习 | 个体学习，附策略版本和更新状态 |
| 无 Laya 小网络 | 检验学习网络本身能做到什么 | 小网络对照 |
| 回放 | 执行此前记录的动作 | 录制回放 |
| 故障降级 | 模型不可用时显式改用规则 | 降级及原因，记录开始和结束位置 |

严格实验模式下模型失败默认暂停，不自动降级。探索模式可启用明确标识的规则降级。降级数据不得混入“纯 Laya”实验结果。

首版同一实验使用同一种大脑架构，但个体参数与经历独立，不共享后天经验。混合种群、群体共享训练与 Jev 接入属于后续扩展。训练中、冻结评估、暂停学习是独立于大脑类型的状态。

### 世界提出的学习问题

三个机制都属于已确认的方向，按阶段逐步实现，不要求第一轮同时开放：

1. **资源环境变化**：食物从稳定聚集变为分散，再恢复旧分布，观察适应与旧能力保留。首个学习版本即包含此机制。
2. **延迟后果食物**：提供可观察但不直接标注含义的食物特征，摄入后延迟产生损伤，检验长期后果关联。主学习闭环验证后实现。
3. **有成本的信号与分享**：发送信号和资源转移产生真实代价，接收者能否从经历学会使用信号需要验证。延迟反馈实验之后实现。

环境变化计划与毒性真值仅供模拟器和观察者使用，不直接告诉生命体正确行动。遗传演化与个体学习都保留，通过实验分别测量。

## 5. 前端与视觉

完整开发前通过 P0 制作线框、视觉稿和可点击原型，先审核核心体验。视图、状态与走查脚本见 [产品原型计划](PROTOTYPE.md)。此文的视觉描述不等于视觉稿已完成。

视觉方向为深色显微生态：墨蓝或深绿水域、带细微轮廓的半透明生命体、缓慢流动的营养层、克制的柔光。视觉颜色和形态优先映射可解释数据，例如谱系、体型和能量。

- 中央画布占主要面积，支持缩放、拖动、选择、跟随与适配视野。
- 顶部显示模拟时间、种群、大脑模式、学习状态、暂停与速度；等待推理或训练时有状态提示。
- 右侧为按需展开的个体观察面板，显示性状、能量、感知、记忆、Laya 原始偏好和个体策略的最终动作分布。
- 成长时间线关联实际经历、反馈与策略版本；支持在同一许可观测上比较旧策略与新策略，明确标注这是固定输入的比较，不等于实际生存收益。
- 底部提供种群曲线、事件时间线与谱系入口，避免面板长期遮挡世界。
- 干预工具包含投放营养、绘制障碍、移除障碍；操作在模拟步边界生效。
- 信息不能仅靠颜色表达；状态同时有文字、图标或形态区别。
- 尊重减少动态效果设置；窄屏优先折叠面板而非缩小所有文字。

首版至少包含三种可同时出现的基础体型：柔团、尾游、节虫；这是同一套世界视觉中的生命多样性，不是三选一的主题。各自保留舒展收缩、转向冲刺、分节推进的动作特点，并可在体型、膜纹和比例上产生个体差异。当前仅确认共存方向，外形细节未定稿。角色不预设善恶或聪明程度；形态不等同于物种、策略或学习能力。功能性差异若影响消耗、速度或感知，需要另行定义并验证模拟规则。首版生命体轮廓随体型与谱系变化；不将美术形变宣传成多细胞形态发生。

## 6. 可观察性

记录种群数、出生死亡率、资源与体内能量、动作比例、性状分布、谱系长度、推理和训练耗时、降级比例，并加入个体学习次数、奖励分项、环境变化后的恢复时间和冻结评估结果。

事件必须由模拟数据产生，例如“谱系 L-12 最后一个个体死亡”。解释面板可显示“观测：附近无食物；Laya 偏向：休眠；个体策略选择：探索；结果：能量下降；策略版本：12 → 13”，不能凭空写“它感到孤独”。只有实际指标支持时才显示“能力改善”，参数更新本身只标为“已更新”。

复杂行为需要定义测量标准。聚集可能只是共同追逐食物，不能直接称为合作；通信效果需用关闭信号的对照验证。

## 7. 首版与后续边界

基础生态交付包含资源、遗传、记忆、真实固定 Laya、规则对照、前端与回放，属于 M0–M4 阶段成果。**面向用户的首个学习版本还必须包含 M5：个体轻量学习网络、变化资源实验和成长展示。** 不能在交付基础生态时宣称完成持续学习目标。

后续按验证结果逐项增加：

1. 延迟后果食物，检验长期反馈的关联。
2. 有限信号与资源分享，检验信息使用与群体协作。
3. 捕食、防御、温度、季节和局部灾害，扩展生态压力。
4. 主路线跑通后扩展另外两条学习路线：固定 Laya + 经验统计，以及直接持续微调 Laya；小网络消融对照在主路线验证时就需要。
5. 经验传承、群体共享学习、可演化网络结构、Jev、形态扩展、自动实验搜索与公开展示。

不在首版同时加入以上所有机制。每次扩展都应带一个可观察问题与对应对照。
