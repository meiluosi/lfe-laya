# 预注册 07：匹配训练下 Laya 与情感词典的比较，以及延迟 40 → 80 的趋势

状态：**假设与协议在训练开始前冻结**（冻结提交见 §9；48 个基因组的哈希在训练完成后、评估前追加）。冻结后不得修改 §2–§5。

## 1. 来源与动机

预注册 06 在匹配训练下确认：先验在延迟 0 的世界里中性（laya − none = +0.015），在延迟 40 的世界里稳定有益（+0.0485，6/6 种子）。但它没有回答最关键的比较：**Laya 在个体适应度上是否比简单的情感词典（VADER）更好？** 预注册 02、03 中该比较（H3）不成立，但当时训练与评估错配，且描述靠褒贬词就能读。预注册 05 显示在需要世界知识的事实方言上，Laya 的先验质量（AUC 0.775）远高于 VADER（0.583）。本次在匹配训练下检验这个差距能否转化为适应度；同时检验先验的价值是否随后果延迟继续增加（延迟 80）。

## 2. 被测系统（冻结）

先验 {laya, none, vader} × 制度 {d40, d80} × 8 个训练种子（31–38）= 48 次独立进化；个体均为 flat（结构化个体 v2，9 个基因，无层次信念）。训练设置与预注册 06 相同：40 代，种群 24，σ 0.25，学习率 0.1，每代 6 个训练世界（训练方言词池），K=32，危害封顶 4，所有训练世界使用该制度的延迟（`--delayAll on`），欺骗按 0.25 / 0.40 循环。命令模板：

```
node packages/evo/semantic-evolve.ts experiments/evo/f7-<laya|none|vader>-<d40|d80>-<s> \
  --prior <laya|none|vader> --learning on --agent structured --pool on --K 32 --harmCap 4 \
  --delay <40|80> --delayAll on --inversions 0.25,0.4 --worlds 6 --generations 40 --pop 24 \
  --sigma 0.25 --lr 0.1 --seed <s> --workers 1
```

训练种子 s 在各格间共享（相同的进化噪声序列），按 s 配对。训练后不得挑选、重训或剔除任何基因组。

## 3. 评估世界（冻结）

- **留出方言池**（`heldout`，已在预注册 02–04、06 评估过，见 §6）与**事实方言池**（`factual`，需要世界知识的描述）。两个池的 Laya 先验表都是缓存的、只依赖文本。
- 每个制度只在与其训练匹配的延迟下评估（d40 → 延迟 40；d80 → 延迟 80）；欺骗 {0.25, 0.40} 两个单元，每单元 32 个新世界（留出池世界种子 200000 起，事实池 210000 起，各单元与制度错开）。K=32，危害封顶 4，8 个个体，无繁殖。
- 指标：适应度 = 0.7×存活占比 + 0.3×终态队列能量占比；同时报告毒食物次数与存活率。

## 4. 假设（冻结）

分析单位是训练种子（8 个，按种子配对）；每个种子先在两个欺骗单元与世界上取均值，再做差。

- **H1（Laya 优于情感词典）**：制度 d40，**事实方言池**：laya − vader 的 8 个种子平均差 **≥ +0.03**。
- **H2（延迟更长时先验仍有益）**：制度 d80，**留出方言池**：laya − none 的平均差 **≥ +0.04**。
- **H3（先验的价值随延迟增加）**：**留出方言池**：（laya − none）@d80 − （laya − none）@d40 的平均差 **≥ +0.02**。

## 5. 统计方法（冻结）

- 符号翻转精确检验：8 个种子，2^8 = 256 种符号，p = 符号翻转后均值 ≥ 观测均值的比例（最小 p = 1/256 = 0.0039）。
- Holm 逐步检验**只基于 p 值**：按 p 从小到大（并列时按 H1、H2、H3 的顺序）比较 α/3、α/2、α（总 α = 0.05）；一个假设在 Holm 中未被拒绝，其后的都不拒绝。“成立”= Holm 拒绝 **且** 该假设自己的效应量条件满足；效应量条件不满足不会阻断其他假设（同预注册 06 §5）。
- 次要（描述性）：另一个池上的同一比较（留出池上的 laya − vader；事实池上的 laya − none）；vader − none；毒食物次数；各欺骗单元；完整的格均值。
- 不成立或模糊时如实报告，不换比较、不换指标、不加种子、不重跑。

## 6. 已知限制（预先声明）

1. 8 个训练种子仍是小样本。
2. 训练只用训练方言（情感倾向明显，VADER 在其上有一定判断力：此前测得 AUC 约 0.69），评估包含事实方言，所以 H1 同时包含“跨方言泛化”。Laya 与 VADER 个体都在同一训练方言上学会了“多信任先验”，这对两者对称，但事实方言上 VADER 的先验几乎无信息，Laya 的先验有信息，差异因此被放大；这正是 H1 要检验的，不是缺陷，但读者需要知道。
3. 留出方言池已在预注册 02–04、06 中被评估多次（只看汇总，未用于调参、选基因组或改协议）；事实方言池对个体只在预注册 06 中作为次池评估过一次。
4. 延迟 80 比之前的任何评估更长；个体的信用窗口基因上限为 150，是否足够由进化决定；初始值沿用 50（延迟 > 0 时），如果 d80 个体的窗口被限制，这是协议的一部分。
5. 其余同预注册 02 §8。
