状态：计划与检查清单，不是已执行的发布。**任何对外发布（公开仓库、上传 arXiv）都需要用户另行明确指示**；当前仓库 `meiluosi/lfe-laya` 为私有。最近更新：2026-10-11。

## 1. 论文的定位（据现有证据）

标题方向：固定的预训练决策模型作为进化个体的先验：一项受控、预注册的研究（Laya 作为系统 1）。

可以主张的：
1. 一套让“先验 / 进化 / 终身学习”贡献可分离的世界复杂度阶梯与闸门（生成式本体、致命 / 延迟 / 欺骗）。
2. 固定 Laya 在没有微调的情况下，对新写法与需要世界知识的描述有较高的区分力（留出方言 AUC 0.909；事实方言 0.775 对词典 0.583），并有选项顺序偏差及处理方法。
3. 先验被欺骗时有代价；自适应信任可缓解（开发期证据）。
4. 方法学：预注册、留出方言、重复种子，如实报告负面结果（预注册 03 中 H1/H2 的大效应没有被稳定复现）。

不能主张的（除非后续预注册支持）：先验稳定提升个体适应度；Laya 优于情感词典的适应度收益；“首个”。预注册 04 的结果（延迟更长 / 欺骗更强世界里的价值与稳定性）将决定第 3 点之外的叙事。
