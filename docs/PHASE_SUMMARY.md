## 3. 负面与未达预期（必须随正面结果一起说）

1. **种群层面无优势**（预注册 19）：建立率 +0.016（阈值 +0.08），个体数 +2.8%（阈值 +10%），恢复比 −0.011（阈值 +0.05），均不显著，种子间方向不一致。开发期 2 个种子的小正差在 8 个种子上没有重现。可能原因（未检验）：繁殖世界里存续主要由攒能量繁殖决定，吃对率的几个百分点差被食物供给和繁殖阈值吸收。
2. **cue 依赖线索**：线索关闭时 cue 个体比普通学习更差（预注册 18：abab / long 无线索适应度 .23–.26）。它把线索当标签，没有被理解；这是“线索未被理解”的又一证据。
3. **Laya 读不出环境线索**（G9 两次探针）。线索对 cue 有用，但必须由人给标签。
4. **幅度**：长停留后的保留（+0.167，阈值 +0.20）、第二次反转后的再学习（+0.043，阈值 +0.05）未达预设幅度，按“方向确认、幅度不足”记录，未改阈值。
5. **较早的修正**：预注册 02 的大效应在 3 个训练种子重复里没有稳定复现；延迟世界里先验的优势有很大一部分是弥补弱的经验学习器（预注册 13：换成延迟感知的学习器后，优势 +0.091 → +0.017，区间含 0）；进化个体相对手写学习者无显著优势。
6. **长停留繁殖世界不可评估**（建立率 0）；**混合种群**占比被漂变主导，与中性对照不可区分，只能描述。

## 4. 方法与纪律回顾

- 全部确认性比较走“协议冻结提交 → 训练 → 基因组哈希 → 一次性评估”，共 19 批预注册（M0 之后的 02–19），冻结与结果均有 git 提交作时间戳。
- 每次都预先写出效应量阈值，并区分“Holm 拒绝”与“幅度达标”；预期会失败的假设（如预注册 18 的 H1、预注册 19 的 H1–H3）事先写明，失败如实记录。
- 偏离记录：预注册 18 评估中断后以同命令重跑；预注册 19 的中性对照基因组与协议不符（实际用 plain，描述性，未重跑）；校准的并列判据按主规则排序并披露；一次校准前的功能测试已删除并披露。
- 先天 / 后天 / Laya 感知三个来源始终分别标注；隐藏真值不进入个体输入；Laya 权重全程固定。

## 5. 已知限制

- 世界是模板化的食物场景（K=6 的小世界），由作者撰写的三套方言，测试方言已多次使用；留出池被多次评估（未用于调参）。
- 种子数小（多为 8），区间为种子间；基因组在不繁殖的 3 阶段世界里训练，之后的所有结果都是分布外检验。
- regime 最多 4 张信念表，表满后的行为是实现细节，不代表记忆容量。
- Laya 为 421M 模型，按文本缓存先验，吞吐不外推到更大规模。
- 繁殖是固定本能；世界参数来自降级校准；繁殖世界的结论只对该简化机制成立。
- 前端的结论是“能显示”，不是用户研究；一个冒烟测试条目偶发不稳（原因未查明，见 `FRONTEND_REDESIGN.md`）。
