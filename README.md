# LFE / Laya Life Lab

一个可以观察、干预和比较的 AI 人工生命生态缸。

> 状态：P0 已实现并按反馈修订，待用户复核；M0 已完成真实本地推理、独立学习、预定对照、恢复与展示验证。出现小样本收益信号，但不等于完整生态或持续学习已成功。见 [实验结果](docs/m0/RESULTS.md) 与 [完成审计](docs/m0/ACCEPTANCE.md)。
> 更新：2026-09-30。项目名称为暂定名。

2026-09-29 已获授权推进下一轮实验及 M1–M5，目标执行中，见 [当前执行记录](docs/EXECUTION.md)。历史原型与 M0 记录仍可查看；后续能力按实际验收更新。

我们希望构建一个显微镜下的异星生态：生命体在有限资源中感知、行动、繁殖和死亡，Laya 参与行为选择，用户通过改变环境观察个体与谱系的命运。

核心方向：**世界提供值得学习的问题，生命通过经历改变行为，前端把这个过程展示出来。**

算法是项目核心，行为丰富度和适应效果由模拟、决策与学习机制产生；展示端默认简洁，算法细节按需展开。三种基础体型共同保留，外观与动效不能替代算法效果证据。

核心问题：同一个生命能否在一生中根据后果学会新的生存方法，在环境变化后继续适应，并在旧环境返回时保留或恢复已有能力？通过规则、固定 Laya、记忆适应与独立小网络等对照，判断学习和 Laya 分别起到了什么作用。

## 运行 P0

```sh
npm ci
npm run dev
```

访问 [本地观察室](http://127.0.0.1:5173)。一键验证：`scripts/verify.sh`（加 `--ui` 含浏览器冒烟，见 [工程与性能优化](docs/OPTIMIZATION.md)）。构建：`npm run build`。本轮已在 Node 24.7.0 下运行；当前需要支持 WebGL 的浏览器。

打开即进入推荐世界，可用场景按钮切换。跟随 L-017，查看经历，再尝试投放营养和创建示例对照。画面始终标记示例；未连接模型、不进行训练、不保存世界。

## 当前建议

- 以二维生态缸为第一版；按 M0 测量，后续从 8 个体、每模拟秒一次决策起步，等待决策完成再推进；不承诺 48 个体实时学习。
- 先实现资源、能量、局部感知、短期地点记忆、无性繁殖与性状变异。
- 主路线为共享固定的本地 Laya + 每个个体独立的轻量学习网络与记忆，保留规则及固定 Laya 对照。
- 前端采用深色水域、半透明生命体与克制的科学观测界面。
- 先验证可变化资源环境中的个体学习，再加入延迟后果食物、有成本的信号与资源分享；保留遗传和自然选择，并分别测量其作用。
- 主路线跑通后再扩展“固定 Laya + 经验统计适应”和“直接持续微调 Laya”两条备选。简化的记忆对照可提前用于验证。

本项目属于模型参与的人工生命实验，不声称生命、意识或智能从零产生。预训练模型带有先验知识；种群演化与模型训练是不同机制。
